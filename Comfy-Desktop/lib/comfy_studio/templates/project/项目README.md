## 这个目录怎么用

一剧一目录。资料按**粒度**分开放，不按"后来想起来"放：

| 想看什么 | 去哪 |
| --- | --- |
| 跨集共用的设定（分集大纲与三表、角色小传） | `00_PROJECT/01_剧本/00_总纲/` |
| 某一集的正文 | `00_PROJECT/01_剧本/` |
| 角色 · 服装 · 道具 · 场景 · 表情 · 姿态 资产 | `02_CHARACTERS/` … `07_POSES/` |
| 分镜 · 镜头 · 一致性报告 | `08_STORYBOARDS/` `09_SHOTS/` `10_CONSISTENCY/` |
| 对白表与配音单 | `00_PROJECT/06_对白/` |
| 音频 | `11_AUDIO/` |
| 原著与素材授权 | `00_PROJECT/07_素材归档/` |
| 台账与流程 | `00_PROJECT/03_台账/` `00_PROJECT/05_流程/` |

## 空表是"待办清单"

建档时预置的表里写着 `（待填）` 的格子就是还没人做的格子。那不是"模板忘了替换" ——
**它是在说这一格还没填**。

> `comfy_studio/projects_spec.py` 的 `PROJECT_DIRS` —— 改了那边，这里才会有新的一行。
