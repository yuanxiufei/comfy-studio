# presets/ —— 随包附带的成品智能体

这里每份 `.md` 都是**完整人设规格**，一份一个智能体。它们在面板的智能体下拉里直接可选；选中后
**整份正文原样**拼进系统提示词（底座规则之下那一段角色段，见 `agent/loop.py` 的
`compose_system_prompt`）。

## 与代码的关系

`agent/catalog.py` 的 `PRESET_AGENTS` 是这些的清单：

| 清单里的 id | 下拉显示名 | 文件 | 体量（字节 ÷ 1024） |
|---|---|---|---|
| `storyboard` | 分镜导演助手 | `分镜导演助手_完整迁移配置.md` | 41 KB |
| `script` | 剧本创作 | `AI剧本创作_完整迁移配置.md` | 48 KB |
| `video` | 视频生成 | `AI视频生成_完整迁移配置.md` | 40 KB |
| `costume` | 服化道设计 | `AI服化道智能体_完整迁移配置.md` | 31 KB |
| `asset` | 角色道具资产库 | `AI资产库角色道具_完整迁移配置.md` | 25 KB |
| `voice` | 调音大师班 | `调音大师班_完整迁移配置.md` | 35 KB |
| `lyrics` | 歌词创作 | `Suno歌词大师_完整迁移配置.md` | 42 KB |

清单提供 **id / 下拉显示名 / 一句说明**，这里的文件提供 **正文**。

为什么名字不直接从文件里读（用户放到 `--agents-dir` 的那些是直接从 `# 标题` 与 `>` 引用读的）：
这些标题带着「完整迁移配置」这类**用途**标记（见每份开头），直接拿来当下拉项又长又乱；
标题下面那段引用块时有时无（`AI剧本创作` 与 `AI资产库角色道具` 两份就没有，紧跟
标题的是二级标题）。面板上显示成什么，与文档里写了什么，是两件事。

## 改这里要注意

- **正文一字不改地进系统提示词**：改文件就等于改这个智能体的行为，不必动代码。
- **增删/改名文件要同步 `PRESET_AGENTS`**：清单与目录对不上时会有一条测试失败
  （`tests/test_agents_tools.py` 的 `test_a_preset_that_is_missing_is_reported` 与
  `test_every_preset_file_is_listed`）。这不是形式主义 —— 清单里的文件名拼错时，那个智能体
  会从下拉里消失，只在 `problems` 里留一行，不跑测试很难发现。改了源规格的那一轮
  `_build.py` 会**替你先查一遍**（报「清单里缺 …」并返回非 0）。
- **正文会整份发给模型**：每份 1.6–3.2 万字符（约 0.8–1.6 万 token）。选中哪个才带哪个，但那一轮
  每一轮都带 —— 这是完整规格的代价，写在这里免得日后被当成"提示词怎么这么大"的 bug。
- **不要往这里放用户自己的智能体**。用户的文件放 `--agents-dir`（默认是工作台数据目录下的
  `agents/`）：那个目录每次开面板都现扫，用户随时能改；这里是随包内容，跟版本走。
  用户文件与这里 **id 相同**时以用户那份为准（他的文件覆盖随包预置，见 `catalog.py` 的
  `scan`）。

## 用途：整份带走 —— 以及它与派生 agent 的关系

这些文档**自包含**：不依赖本仓库的任何代码，复制到别的平台就能当 System Prompt /
Instructions 用；每份开头都写着「用途：将本智能体迁移到其他 GPT / Agent / 工作流平台时，
作为完整的行为规范、输出规范与提示词生成规范」。

⚠️ **这些就是权威源**（写作地）。2026-09-28 之前它们另存一份在引擎侧
`manju/智能体搭建参考md/`，两份并存的理由有两条：

* 引擎侧正文里的 `智能体搭建参考md/…` 引用以那边为基准 —— **引擎侧那棵树整体删除后，
  这条理由随之消失**；
* 宿主包要随桌面壳分发、cwd 是壳自带的 lib，猜不到用户的 ComfyUI 装在哪 —— 这条仍然
  成立，也正是这些**必须**住在包内的原因。

既然住在包内删不掉，再在别处留一份"权威源"就是**同一知识两处维护**：改了源、忘了同步
既不报错也不复现（症状只是面板下拉里那个智能体按旧人设说话）。于是源就此收敛到这一处。

派生只有**一条**：`.codebuddy/agents/studio-<职责>.md`（给 CodeBuddy 主 Agent 用）。

**改规格**：

1. 直接改本目录里那份（**改文件就等于改这个智能体的行为**，不必动代码）；
2. `python .codebuddy/agents/_build.py` —— 重生成那一批派生 agent（`--预览` 只算不写）。

脚本会顺带核对两件事：`agent/catalog.py` 的 `PRESET_AGENTS` 是否登记了这些（没登记 =
下拉里静默少一项），以及 `.codebuddy/agents/` 里有没有**改名 / 删源之后遗留的孤儿**
（它不在生成清单里，却还被主 Agent 看见 —— 照着过时规则干活）。

漏了也不怕：引擎侧 `comfy_studio/tests/test_agent_presets.py` 会拿同一份渲染逻辑重算并
逐字比对派生 agent（抓"改了源没重生成"与"手改了生成物"），宿主侧另有一套清单一致性测试
（`tests/test_agents_tools.py`）。⚠️ 本目录**不放**对应的对拍：这个包要能跟着桌面壳单独
分发，在这儿往上找仓库根、找不到就跳过，只会变成"换台机器就永远不跑"。
