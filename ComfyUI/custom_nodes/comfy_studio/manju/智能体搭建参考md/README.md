# 智能体搭建参考md/ —— **对外迁移配置**（不是本仓库的权威规则）

> 本目录收录 6 份「**完整迁移配置**」。它们的用途是**把智能体迁移到其他平台** ——
> 每份规格都自己写明了这一点，例如最近更新的那份：
>
> > 用途：将本智能体**迁移到其他 GPT / Agent / 工作流平台**时，作为完整的行为规范、
> > 输出规范与提示词生成规范。
> > 建议：将本文档主体内容复制到**目标智能体**的 System Prompt / Instructions 中……
>
> 且它们都**自包含**：不依赖本仓库的任何代码，复制走就能用。

---

## 一、⭐ 与工作流的分工（**别把这两个当成"两个权威"**）

| | **本目录** | `AI漫剧智能体工作流/` |
|---|---|---|
| 定位 | **对外迁移配置** | **本仓库的权威规则 + 可执行实现** |
| 形态 | 自包含 prompt / spec，无依赖、无代码 | 规则文档（23+ 份） + `07-智能体运行时` 的 Python |
| 强制力 | 只能**描述**规则（靠模型遵守） | ID 分配 / 版本号 / 一致性 Gate / 锁定指纹 / 参考图链 / 漂移检测**由代码强制** |
| 何时看它 | **要迁出**（在别的平台复刻这个 agent） | **在本仓库干活** |

**所以「哪份权威」这个问题不存在** —— 用途不同：

- **在本仓库内工作** → 以 `AI漫剧智能体工作流/` 为准（那是本仓库的产物规范与代码行为）；
- **要迁到别的平台** → 以本目录的对应规格为准（那是"带走的那一份"）。

⚠️ **两者不自动同步。** 改了工作流 ≠ 本目录跟着变，反之亦然。
「要不要同步」是**人工决定** —— 用途不同，**允许不同步**，
但**不允许在没意识到的情况下不一致**，故把这条写在这里。

> **依据（实测）**：`AI漫剧服化道智能体_完整迁移配置.md` 与工作流 `02-服化道/`
> 互含率 **0.0%** —— 它们本就是两件东西；而**该规格的旧版**与工作流
> `02-服化道/00-主控智能体.md` 曾 **100% 同一份**，所以当时判定"不该再存一份副本"。
> ⚠️ **判据随事实而变** —— 源文件一更新，结论就得重算。

## 二、命名约定

```
<名称>_完整迁移配置.md
```

统一掉了此前三种不一致：分隔符 `｜` vs `_` · 后缀 `完整迁移版` / `完整迁移配置` /
`_Markdown`（后者纯冗余，本来就是 .md）· 名称里夹的描述性长尾。

> ⚠️ **文档内的标题不动**（如 `# Suno 歌词大师｜完整智能体迁移配置`）——
> 那是**内容**，不是文件名。

```bash
python .codebuddy/agents/_build.py
python AI漫剧智能体工作流/07-智能体运行时/tests/test_agents.py   # 含"生成物 == 重算"检查
```

> 要装到 CodeBuddy **用户级**（`~/.codebuddy/agents/`，对**本机所有项目**生效）→ 见 **§五**。

## 四、新增/更新规格时

1. 命名按 §二 的格式；
2. 若是**新模块**的规格，在 `.codebuddy/agents/_build.py` 的 `SOURCES` 加一行
   （`module` / `mode` 必填 —— 自动入口需与联动型一起对上 `tests/test_agents.py` 的**名册**）；
3. 重跑生成脚本 + 校验测试（要同步到用户级，就再补 §五 的第 ② 步）。

## 五、部署到 CodeBuddy **用户级**（`~/.codebuddy/agents/`）

§三 那 6 个移植型 + 7 个联动型，**都能装到用户级** —— 装上后对本机**所有项目**生效
（不限于本仓库）。安装器：`.codebuddy/agents/_install_user.py`。

```bash
python .codebuddy/agents/_build.py                  # ① 按本目录重生成（项目级 = 权威源）
python .codebuddy/agents/_install_user.py           # ② 装到 ~/.codebuddy/agents/
python .codebuddy/agents/_install_user.py --校验     # 只比对不写盘；不一致 → 退出码 1
python .codebuddy/agents/_install_user.py --卸载     # 撤掉本批
python .codebuddy/agents/_install_user.py --仅移植型  # 只装本目录这 6 个（自包含，不依赖本仓库）
```

安装**不只是复制**，做三件事 —— 每件都对应一个"会静默失效"的坑：

| | 做什么 | 为什么 |
|---|---|---|
| ① | **路径绝对化**：`AI漫剧智能体工作流/…`、`07-智能体运行时/…` → 绝对路径 | 用户级 agent 会在**别人的项目**里被调用，那时 cwd 不是本仓库，相对路径必然失效 |
| ② | 正文最前**声明路径基准**（仓库根 / 工作流根） | 剩下的裸写法**无法全局替换**：`02-服化道/…` 是相对**工作流根**，而 `01-声音设计引擎.md` 是相对**模块目录** —— 硬替换会改写错语义，只能说明白 |
| ③ | 标注**派生关系**（权威源 + 重装命令） | 直接改用户级那份，会在下次安装时被**静默覆盖** |

⚠️ **路径替换必须单遍完成。** 分遍做（先 `AI漫剧智能体工作流` 再 `07-智能体运行时`）时，
第二遍会命中第一遍刚生成的那段，得到
`…/AI漫剧智能体工作流/D:/…/AI漫剧智能体工作流/07-智能体运行时` ——
**不报错、还挺像路径**。故安装器内置签名自检，`tests/test_agents.py` 也钉住了「单遍 + 幂等 + 注记声明基准」。

⚠️ 用户级那份是**派生物**：改规则一律**改本目录的规格** → 重跑上面 ①②（+ 校验）。

⚠️ **用户级 ≠ 项目级**：用户级只在**本机**有效，不是仓库交付物，
所以校验分两处（`tests/test_agents.py` 看项目级；`--校验` 看用户级）。
