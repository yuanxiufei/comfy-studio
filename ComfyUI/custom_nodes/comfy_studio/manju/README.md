# manju

> AI 漫剧生产的**智能体提示词工程**项目 —— 一句话创意 → 可发布单集。

---

## 🎬 这是什么

一套**可部署、可自检**的 AI 漫剧生产智能体。把「写剧本 → 做资产 → 拆分镜 → 出视频 → 配音乐 → 过审」六个环节，做成六份可独立部署的智能体规格 + 可执行的规则引擎。

**核心定位**：agent 负责「**想清楚 + 写准提示词**」，人负责「**确认方向 + 按按钮生成**」。

---

## 📁 目录

| 路径 | 说明 |
|---|---|
| **`AI漫剧智能体工作流/`** | ⭐ **主体**：六模块规格 + 可执行运行时 + 自检，从这里开始 |
| `智能体搭建参考md/` | 六份 GPTs 迁移配置**原文**。⚠️ 不是参考资料 —— 它是 `.codebuddy/agents/_build.py` 生成「移植型 agent」的**输入**，`tests/test_agents.py` 会载入生成器重算并断言逐字一致 |
| `novel/` | 漫剧原文（**产品数据**）。桌面壳「管理小说」面板的读写落点，`novels/*` RPC 默认指这里（`Comfy-Desktop/lib/comfy_studio/novels.py` 的 `MANJU_REL`） |
| `projects/` | 项目工作区根，一剧一目录，由 `pipeline.find_workspace` 探测 |
| `README.md` | 本文件 |

> ⚠️ **旧版表格里两行已删（实测不成立）**：`data/`（用户素材 4.3 GB）**不在本目录**；
> `.codebuddy/`（agent 定义与生成器）在**仓库根**，不在 `manju/` 下。

## ✨ 特点

| 特点 | 说明 |
|---|---|
| **六模块可独立部署** | 每个模块的主控都能单独挂进 GPTs / Coze / Dify 使用 |
| **单一权威来源** | 同一知识只在一个文件维护，分三层（规格 → 引擎 → 模板） |
| **可自检** | `python 工具/校验.py` 一次跑 7 类检查（引用断链 / 改主控忘改模板 / 前缀残留 / 口径漂移 / 素材误删 / 文本损坏…） |
| **实跑验证过** | 六个模块均经过真实链路演练，曾用演练暴露并修复跨模块机制缺口 |
