```markdown
| # | 原文 | 风险等级 | 优化后 | 采用手法 | 视觉影响 |
|---|---|---|---|---|---|

| 6 | <伤情描写> | P1 | （删除） | 删减 | 信息减少 |

## 优化后完整文本

<可直接复制使用>

## 保留的视觉要点

- <说明核心视觉表达未丢失>
- <说明情节意图未改变>

## 优化红线自检

- [ ] 未改变创作意图（只改表述不改情节）
- [ ] 未破坏视觉逻辑（优化后仍可生成）
```

### 过审优化八法速查

> 与 `00-主控智能体.md` §三 B1 一致。⑦⑧ 为合并源 skill 后新增，**处理反乌托邦与时政类最有效**。

| # | 手法 | 适用 | 做法 | 示例 |
|---|---|---|---|---|
| ① | 抽象化 | 暴力血腥 | 具体 → 概念 | 血 → 暗色痕迹 |
| ② | 侧写化 | 暴力/冲突 | 直接 → 间接 | 打人 → 手停在半空 |
| ③ | 转移焦点 | 血腥/尸体 | 主体 → 反应/环境 | 尸体 → 法医动作 |
| ④ | 术语化 | 违法/犯罪 | 口语 → 专业中性词 | 杀人现场 → 案发现场 |
| ⑤ | 状态化 | 进行中的暴力 | 进行中 → 已完成/未发生 | 捅刺 → 凶器落地 |
| ⑥ | 删减 | 一切 | 删除最激进元素 | 去掉伤情描写 |
| ⑦ | **正向化改写** 🆕 | **反乌托邦/极端生存** | 消极设定整体转正向 | 末日废土互相残杀 → 未来生态重建团结协作 |
| ⑧ | **完全架空** 🆕 | **时政/历史/民族敏感** | 创造全新虚构世界观 | 涉现实政治历史 → 全新架空设定 |

### 其他专项处理

| 情况 | 手法 | 示例 |
|---|---|---|
| 宗教封建迷信 | 文化正向化 | 驱鬼仪式/邪术害人 → 传统文化庆典/民俗艺术表演 |
| 公众人物/品牌 | 虚构原创 | 现实人物/品牌 → 原创角色/虚构品牌 |
| 低俗/伦理 | 公序良俗 | 暴露/性暗示 → 健康着装 + 正向价值观 |
| 危险动作 | 安全处理 | 详细危险动作 → 艺术化处理，去除可模仿细节 |

## 三、IP 风险评估

```markdown
# IP 风险评估

**检查对象**：<作品 / 角色 / 设定>
**检查维度**：角色相似度 / 设定相似度 / 剧情结构 / 视觉风格 / 名称标题

## 安全项

| 项目 | 说明 |
|---|---|
| 类型模板借鉴 | 安全（类型不受版权保护） |
| 原创人名地名 | 安全 |
| ... | |

## 需调整项

| 项目 | 相似类别 | 相似点（列 3 个以上组合特征） | 调整建议 |
|---|---|---|---|
| <角色外观> | <某类知名角色特征组合> | ① ② ③ | 更换发色 + 改变标志配件 + 调整配色 |

## 高风险项

| 项目 | 说明 | 建议 |
|---|---|---|
| <专有名词体系> | 与特定作品雷同 | 全部重命名 |

## 总体判定

<安全 / 需调整后使用 / 高风险不建议>

## ⚠️ 免责说明

本评估基于通用特征比对，不构成法律意见。
如涉及具体作品比对，建议用户自行核查或咨询专业法律意见。
```

### IP 检查五项

| # | 检查项 | 风险信号 |
|---|---|---|
| 1 | 角色相似度 | 发型+服装+配色+特征组合高度相似 |
| 2 | 设定相似度 | 专有名词体系雷同（宗门/功法/境界/地名） |
| 3 | 剧情结构 | 与特定作品标志性桥段逐场对应 |
| 4 | 视觉风格 | 明确模仿某作品/画师的可识别风格 |
| 5 | 名称标题 | 与已有作品名高度近似 |

**判定标准：**
- **安全** — 仅借鉴类型模板，人名/地名/功法/情节全原创
- **需调整** — 出现 2 个以上高度相似的组合特征
- **高风险** — 专有名词体系雷同，或标志性桥段逐场对应

```markdown
| 2 | 无真实品牌/商标 | ☐ | |
| 3 | 暴力元素已侧写化 | ☐ | |
| 4 | 无暴露/擦边画面 | ☐ | |
| 5 | 无恐怖形象 | ☐ | |
| 6 | 无违法内容演示 | ☐ | |
| 7 | 无政治/宗教敏感符号 | ☐ | |
| 8 | 无文字/水印污染 | ☐ | |
| 9 | IP 相似度已检查 | ☐ | |
| 10 | 音乐/音效版权已确认 | ☐ | **回查 OPEN-ISSUES**：所有版权类 BLOCKING/MAJOR 项须为 CLOSED |
| 11 | 平台规则已对照 | ☐ | |
| 12 | 标题/封面无违规 | ☐ | |

**结论**：☐ 可发布 ☐ 修改后发布
```

### 第 10 项的判定逻辑（防假通过）

```
查 00_PROJECT/OPEN-ISSUES.md
→ 所有「版权授权」类的 BLOCKING / MAJOR 项是否均为 CLOSED？
   是 → 第 10 项 ✅
   否 → 第 10 项 ❌，整体判定降为「修改后可发布」

⚠️ 不得由本模块自行判定"应该可以商用"——版权类必须用户确认。
```

### 措辞要求：核查登记项，而非首次发现

```
❌ 错误："发现音乐版权风险，建议确认授权。"
   → 潜台词：现在才发现，可能已白做

✅ 正确："OI-001（音乐商用授权）登记于启动阶段，当前仍为 OPEN。
        该问题为 BLOCKING 级，不解决则不得发布。
        需用户确认：① Suno 订阅等级 ② 或更换为已授权音源。
        在此之前可继续生成画面，使用临时音轨。"
   → 潜台词：启动已知、生产未受阻、仅待用户决策
```

## 五、平台风控差异速查

| 平台 | 重点风控 | 建议力度 |
|---|---|---|
| 抖音 / 快手 | 暴力、擦边、恐怖、血腥 | 最高，用侧写化 |
| 视频号 | 与抖音接近，偏保守 | 同抖音 |
| B站 | 相对宽松 | 可保留较多表达 |
| YouTube | 暴力可接受度较高，版权严 | 重点查 IP 与音乐版权 |
| 海外分发 | 文化差异（宗教/民族符号） | 单独审查符号系统 |
