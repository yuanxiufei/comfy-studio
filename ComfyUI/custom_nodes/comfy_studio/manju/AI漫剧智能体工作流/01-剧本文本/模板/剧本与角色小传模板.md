## 一、剧本正文格式（硬标准）

> ⚠️ 格式不可随意改，下游按此解析。

```markdown
【场景1：临江市旧公寓楼道／夜 21:12】

（雨声密集。楼道灯闪烁。地上有一摊积水。）

沈砚从楼梯拐角走上来，脚步在积水里发出声响。他停住，低头。

沈砚：（压低声音）谁放的东西在这。

他蹲下，拾起一个被雨水泡软的牛皮纸档案袋。

【场景2：临江市旧公寓楼道／夜 21:18】

（沈砚已经站起身，档案袋被打开。）

沈砚打开档案袋，里面是一只银色怀表。他拇指按下表盖。

表盘上，指针停在 21:47。
```

### 格式规则

| 规则 | 说明 |
|---|---|
| 场景标题 | `【场景X：地点／时间】`，一部剧内场景编号**连续不重复** |
| 地点 | 必须与 ENVIRONMENT INDEX 中的场景名一致（下游直接映射 `ENV_XXX`） |
| 时间 | 精确到分钟，供分镜表"时间"列使用 |
| 动作描写 | 用 `（　）` 包裹，**只写摄影机可见的动作与物体** |
| 台词 | `角色名：台词` |
| 情绪提示 | `角色名（情绪）：台词`，情绪词需在 §10 十六表情内 |
| 禁止 | 心理描写、括号暗示、书面语台词、旁白交代（除有意设计） |

## 二、角色小传模板

> 每个角色一份。字段对齐 `02-服化道` 的 CHARACTER INDEX 与 Character DNA 需求。

```markdown
## CHR_001｜沈砚

**基础信息**
- 别名：沈队
- 年龄：32
- 性别呈现：男
- 身份／职业：刑警队长
- 社会地位：中层公职

**性格**
- 关键词：寡言、克制、认死理
- 矛盾点：极度理性，却对一件旧案念念不忘

**外貌要点（供服化道直接用，≥5 处）**
1. 偏长方脸型，下颌角清晰
2. 颧骨下有轻凹
3. 眉骨略高，呈眉压眼的细长眼型
4. 鼻梁挺直，鼻尖略下压
5. 薄唇，唇线清晰，习惯抿唇
6. 清瘦但结实，肩宽中偏宽

**关键特征（可识别锚点，1-2 个）**
- 左眉尾一道约 1.2cm 浅白旧疤
- 习惯用左手拇指按压物件

**服装逻辑**
- 阶层：中层公职，穿着朴素无标识
- 场合：常年夜班外勤 → 旧皮夹克 + 深色针织
- 色彩倾向：深灰黑，避免亮色

**内在**
- 核心欲望：查清当年的真相
- 致命弱点：不肯说软话，导致孤立
- 人物弧光：从"独自扛" → "学会信任同伴"

**台词特征**
- 语速：偏慢
- 用词：短句、少形容词、不用敬语
- 口头禅：（无，刻意不设定）
```

### 角色小传必填项检查

- [ ] ID（`CHR_XXX` 格式，**且已在 ID 注册表中登记**）
- [ ] 外貌要点 ≥5 处（含脸型/眉眼/鼻唇/肤色/体型）
- [ ] 关键特征 1-2 个（下游作 Signature DNA）
- [ ] 服装逻辑（阶层/场合/色彩倾向）
- [ ] 人物弧光（影响后续状态派生 `_State_X`）
- [ ] 台词特征（影响配音选角）

> **后续集才出场的角色**：此刻只需在 ID 注册表占号并标 `RESERVED`，**不必写完整小传**，等其出场集再补。

```markdown
| 集 | 时长 | 核心事件 | 开场钩 | 集尾钩 | 情绪强度 | 出场角色 | 出场场景 |

| EP01 | 90s | 沈砚在旧楼发现父亲遗物怀表 | 雨中空镜 + 突兀脚步声 | 怀表指针停在 21:47 | 6 | CHR_001 | ENV_001 |
| EP02 | 90s | ... | ... | ... | 7 | | |
```

### 节奏校验

- [ ] 每集有开场钩 + 集尾钩（≥2 个钩子）
- [ ] 情绪强度有起伏（不得连续 3 集同一强度）
- [ ] 关键转折间隔 ≤20 秒（横版）
- [ ] 铺垫长度 ≤15 秒（横版）
- [ ] 单集 60-180 秒
