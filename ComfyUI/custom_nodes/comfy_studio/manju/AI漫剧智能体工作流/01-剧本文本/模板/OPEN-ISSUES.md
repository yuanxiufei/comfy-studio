# OPEN ISSUES — 未决项跟踪表

> **本表在项目「启动阶段」创建，全程跟踪，直到发布前全部关闭。**
> 落盘位置：`AI_DRAMA_PROJECT/00_PROJECT/OPEN-ISSUES.md`

---

## 一、为什么必须启动阶段就建（核心动机）

**反面案例**：EP01 走通链路时，唯一的真实阻塞是「AI 生成音乐的商用授权」——
但这个问题**到 06 合规阶段才被首次发现**，此时 EP01 已经做完了全部分镜与视频生成。

这个顺序是错的：

```
❌ 错误顺序：做完全片 → 06 发现音乐不能商用 → 全片配乐重做
✅ 正确顺序：启动时登记未决项 → 全程跟踪 → 尽早关闭 → 再做对应内容
```

**规则：凡涉及「外部依赖」的问题，一律在启动阶段登记，不允许拖到被发现时才处理。**

---

## 二、必登清单（启动阶段逐项过）

以下问题**无论是否当前集需要**，都必须在 05 启动阶段登记：

| # | 检查项 | 为什么必登 |
|---|---|---|
| 1 | **音乐来源与商用授权** | AI 生成音乐（Suno/Udio 等）的商用条款随平台变，且常有限制 |
| 2 | **参考图 / 素材版权** | 用作风格参考或合成的图片，其来源是否可商用 |
| 3 | **字体授权** | 字幕/标题字体，大量字体商用需授权 |
| 4 | **角色肖像权** | 若角色外观参考了真人（含自拍、模特照） |
| 5 | **IP 相似度预判** | 若题材接近知名作品，**启动时先做一次预判**，而非成片后 |
| 6 | **平台条款** | 目标平台的 AI 内容政策（是否要求标注、是否限流 AI 生成） |
| 7 | **配音来源** | 真人配音 vs AI 配音，AI 配音的商用条款 |
| 8 | **音效素材授权** | 音效库（Envato 等）的授权范围 |

> 1-8 全部属于「**外部依赖**」——即**不是靠内部努力能解决**的问题，必须用户确认或采购。

## 三、未决项分类

| 类别 | 含义 | 通常关闭方式 |
|---|---|---|
| **版权授权** | 外部素材/内容的商用授权 | 采购 / 换来源 / 用户确认 |
| **平台规则** | 目标平台政策不明或有限制 | 平台文档确认 / 小样测试 |
| **设定未定** | 剧情/世界观尚未确定 | 内部决策 |
| **技术可行性** | 某效果当前 AI 工具做不到 | 降级方案 / 换工具 |
| **预算资源** | 需要付费工具/素材 | 用户决策 |

## 四、严重度与阻断规则

| 严重度 | 定义 | 阻断什么 |
|---|---|---|
| **BLOCKING 阻断** | 不解决则成片**不能公开发布** | 🔴 阻断发布（但**不阻断生产**） |
| **MAJOR 重要** | 影响质量或成本，不解决则需返工 | 阻断该环节进入下一阶段 |
| **MINOR 次要** | 可容忍，记录备查 | 不阻断 |

### 关键规则：阻断发布 ≠ 阻断生产

```
BLOCKING 项未关闭时：
  ✅ 允许继续做分镜、资产生成、视频生成（生产不停）
  ❌ 不允许走「发布前最终检查」的通过
```

理由：音乐授权未定，不代表整片白做——可以先出无声/临时音轨版本，授权到位后替换。**让生产与法务并行，而不是串行等待。**

## 六、各阶段职责

| 阶段 | 谁 | 做什么 |
|---|---|---|
| **启动（05 Step 1 后）** | 05 | **创建表 + 跑必登清单 8 项**，逐项询问用户 |
| 剧本 / 资产 / 分镜 / 视频 / 音频 | 各模块 | 发现新的未决项 → **追加登记**（不改已有项） |
| 每个交付包 | 各模块 | 附带「本阶段未决项变动」 |
| 合规阶段终点（06） | 06 | **核查所有 OPEN 项**（而非首次发现），逐项确认可否关闭 |
| 发布前 | 06 | 检查是否存在未关闭的 `BLOCKING` 项 → 有则**不得判定可发布** |

### 06 的措辞要求

```
❌ 错误（首次发现）：
   "发现音乐版权风险，建议确认授权。"

✅ 正确（核查登记项）：
   "OI-001（音乐商用授权）登记于启动阶段，当前仍为 OPEN。
    该问题为 BLOCKING 级，不解决则不得发布。
    需用户确认：① Suno 订阅等级 ② 或更换为已授权音源。
    在此之前可继续生成画面，使用临时音轨。"
```

## 七、关闭权限

| 类别 | 谁能关闭 |
|---|---|
| 设定未定 | 责任模块自行决策 |
| 技术可行性 | 责任模块试做后决策 |
| 平台规则 | 需查证平台官方文档（可内部完成） |
| **版权授权** | **必须用户确认，模块不得自行判定** |
| **预算资源** | **必须用户决策** |

> ⚠️ 版权类未决项**禁止**由 agent 自行判定"应该可以商用"。不确定时的标准回答：提示用户核查。

## 八、与发布前检查的关系

`06-合规审核` 的「发布前最终检查十二项」中，第 10 项（音乐/音效版权已确认）与本表联动：

```
第 10 项判定逻辑：
  查 OPEN-ISSUES → 是否所有「版权授权」类 BLOCKING/MAJOR 项均为 CLOSED
  → 是：第 10 项 ✅
  → 否：第 10 项 ❌，整体判定降为「修改后可发布」
```

**这样避免了"合规表打了勾但版权其实没确认"的假通过。**
