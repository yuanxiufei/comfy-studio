### 01 工业化引擎的核心特点

| 特点 | 说明 |
|---|---|
| **强制前置** | **第一件事不是拆剧情，而是「全人物总建模」** |
| 10+ 高辨识角色 | 每个核心角色必须设计 **10 项记忆资产**（标志动作/表情/镜头/配色/台词风格/服装元素/武器/情绪状态/出场方式/反差点） |
| 30 个爆款标签 | 每角色 1 主标签 + 2~4 辅标签 |
| 群像差异化 6 维 | 身高差 · 发型差 · 脸型差 · 服装层级差 · 色彩差 · 镜头语言差 |
| 18 种禁止角色问题 | 路人脸 / 同模换色 / 同脸换衣服… |
| **单集 2 分钟 7 段时码** | 0-5s 钩子 → 5-20s 事件 → 20-45s 升级 → 45-75s 变化 → 75-100s 反转 → 100-115s 高潮 → 115-120s 钩子 |
| 每集四必须 | 核心冲突 · 信息变化 · 情绪变化 · 结尾钩子 |
| **输入清洗与名词归一**（§2.4） | 真实素材是脏的（meta 残留 / 职务叠加 / 版本改名）——先清洗再建模 |
| 40 集规划骨架（§5.4） | 「**必须先输出**」的分集骨架 + 60/80 集扩展清单（原在 `_规格原文/`，实跑后**回迁**） |
| **9 种角色动态状态** | 黑化/战损/雨夜/疯狂/神性/觉醒/濒死/王座/校园/末世 |
| **9 个状态变量标签** | `[BASE] [EMOTION] [COSTUME] [DAMAGE] [LIGHTING] [ACTION] [CAMERA] [ENVIRONMENT] [STYLE]` |
| 5 组检查器 | 角色记忆 12 项 · 单集提示词 10 项 · 单集节奏 10 项 · AI 可执行性 10 项 · 总检查器 4 域 |
| 禁止偷懒 | 禁止用"这里可以加个反转"代替实际创作 |

## ⭐ 本模块产出两份「项目级共享文档」

本模块是整条产线的**起点**，因此除剧本本身外，还负责创建两份**全流程共用的项目文档**（落在 `AI_DRAMA_PROJECT/00_PROJECT/`）：

| 文档 | 谁在用 | 解决什么 |
|---|---|---|
| **`ID-REGISTRY.md`** | 02/03/04/05/06 全程读写 | 全剧 ID 一次性分配（含**未出场角色的预留号**），避免下文所述三类混乱 |
| **`OPEN-ISSUES.md`** | 各模块追加、06 核查 | 外部依赖问题（版权/授权/平台/预算）**启动即登记**，不让 04 或 06 才发现 |

### 为什么 ID 必须建纲时就分配

EP01 只用到 `CHR_001/002`，反派 `CHR_003` 到 EP03 才出场。若等到 EP03 才分配：

1. **号段冲突**——EP03 想用 `CHR_003`，02 已把 `CHR_003` 用作路人
2. **引用断裂**——大纲写"反派"、资产叫 `CHR_003`，没人确认过它们指同一人
3. **后补成本**——EP03 补角色时 02 要重跑 Gate、01 要回改分镜表

> **规则：ID 在「全剧」层面一次性分配，不在「本集」层面增量分配。号位永不复用。**

### 为什么未决项必须启动时登记

EP01 走通链路时唯一的真实阻塞是「AI 生成音乐的商用授权」，但**拖到 06 才首次发现**——此时全片分镜与视频已做完。

> **规则：凡涉及「外部依赖」的问题，启动阶段一律登记。`BLOCKING` 项阻断发布、但不阻断生产（可先用临时音轨，让生产与法务并行）。**

启动时必过 8 项询问：音乐授权 · 参考图版权 · 字体授权 · 角色肖像权 · IP 相似度预判 · 平台条款 · 配音来源 · 音效素材授权。

## 输出纪律（对齐下游）

**给 `02-服化道` 的：**
- 角色小传含**外貌要点 ≥5 处** + **关键特征 1-2 个**（作 Signature DNA）
- 场景名与 ENVIRONMENT INDEX 命名一致
- ID 按 `CHR_XXX` 格式分配

**给 `03-分镜导演` 的：**
- 剧本正文格式硬标准（`【场景X：地点／时间】` + 动作 + 台词）
- 动作描写只写可见内容（可直接拆分镜）
- 每场戏有明确叙事目的

## 钩子设计速查（短剧命门）

| 类型 | 做法 | 位置 |
|---|---|---|
| 冲击型 | 视觉/听觉冲击 | 前 3 秒 |
| 悬念型 | 抛未解之谜 | 集尾 |
| 反转型 | 颠覆预期 | 中段/集尾 |
| 情感型 | 制造共情 | 中段 |
| 危机型 | 主角陷入险境 | 每集 ≥1 次 |
| 信息差型 | 观众知角色不知 | 贯穿 |

**节奏铁律：**
- 前 3 秒必须有钩子
- 转折 ≤20 秒一次（横版）/ ≤15 秒（竖屏）
- 铺垫 ≤15 秒（横版）/ ≤10 秒（竖屏）
- 每集 ≥2 个钩子

## 写作红线

**绝对不要：** 心理描写 · 括号暗示 · 书面语台词 · 摄影机拍不到的内容 · 旁白交代（除有意设计）

**必须做到：** 台词口语化 · 每场有叙事目的 · 角色出现必附小传 · 场景出现必附场景清单
