## 核心能力

| 能力 | 内容 |
|---|---|
| **平台路由** | Seedance / 可灵 / Vidu / 即梦 / Sora / Runway 差异化提示词形态 |
| **提示词公式** | `[镜头语言] + [主体动作] + [环境细节] + [光影氛围] + [画质参数]` |
| **运动强度五级** | 极弱 / 弱 / 中 / 强 / 极强，含各自动作场景适配 |
| **尾帧链 i2v** | 每镜提取尾帧作下一镜首帧，保证镜头间连续 |
| **场景资产库双锚定** | 空间锚（按景别/方位查参考图）× 时间锚（尾帧），双层保险 |
| **转场设计** | 动作匹配 / 形状匹配 / 遮挡 / 视线 / 硬切 / 跳切 |
| **工程重试层** | 失败先**原参数重试** 2-3 次，仍失败才改提示词 |
| **多镜校验** | 8 项一致性检查表 + 失败登记表（含 retries 列） |
| **失败修复** | 7 类常见失败的处理方案 |

### ⭐ 两个提示词专项库（`引擎/`）

通用提示词公式解决「一镜一个状态」；**这两个库解决「一镜里的变化」与「动作戏怎么拍出打击感」**：

| 库 | 解决什么 | 与主控的关系 |
|---|---|---|
| **`引擎/情绪过渡提示词库.md`** | **从 A 情绪变到 B 情绪**的那几秒怎么演（20 条情绪弧线 + 四段结构公式 + 4 道考题式训练） | 主控管"生成失败怎么办"，本库管"**怎么写得一次就出对**" |
| **`引擎/动作戏提示词库.md`** | 动作戏的**视觉手法**（12 条，每条手法已命名，可与场景解耦复用） | 配套 `03-分镜导演` 的动作戏原则；**同时是合规高危区**（库内有专属预警节） |

> **为什么单独立库**：主控的提示词公式是**骨架**，这两个库是**特定场景的肌肉**。
> 骨架套不进"情绪要变三次"和"拳拳到肉的打击感"这类需求。

### 失败处理顺序（重要，不可颠倒）

```
生成失败 → ① 原参数重试（工程层，可能是服务抖动）
         → ② 改提示词再试（内容层，见失败修复表）
         → ③ 上报用户 + 记入失败登记表
```

> 先做 ① 可避免因服务问题**误改提示词**。

## 上游依赖（缺一不可）

- 来自 `03-分镜导演` 的分镜表（景别/运镜/时长/画面内容）
- 来自 `02-服化道` 的资产 ID（CHR/CST/PRP/ENV）
- 来自 `02-服化道` 的风格英文锚点
- 来自 `01-剧本文本/模板/ID-REGISTRY.md` 的 **ID 注册表**（所有引用 ID 必须已登记）

### ⚠️ ID 规则

| 规则 | 说明 |
|---|---|
| **只引用，不新建** | `CHR_`/`CST_`/`PRP_`/`ENV_`/`POS_`/`SHT_` 全部读取注册表 |
| 本模块唯一可生成的 ID | 派生 ID `VID_<SHT号>`（如 `VID_SHT_S01_006`）与尾帧文件 `<SHT号>_tail.png` |
| 状态门槛 | 只能对状态为 `LOCKED` 的资产出图/出视频；`RESERVED`/`DRAFT` 一律拒绝 |
| 不得自造 ID | 需要新 ID 时回报对应模块（05 或 01）补登记 |

## 关键约束

⚠️ **中文平台严禁英文 tag 堆砌**（Seedance/可灵/Vidu/即梦）
⚠️ **不得虚构平台不存在的参数**
⚠️ **复杂动作场景应降低运动幅度**，否则模型易崩坏肢体
⚠️ **短剧偏好硬切/跳切/遮挡转场**，避免淡入淡出拖节奏
