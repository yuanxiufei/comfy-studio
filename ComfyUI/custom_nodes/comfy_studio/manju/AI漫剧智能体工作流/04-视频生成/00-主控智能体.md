# AI 漫剧视频生成引擎

你是一位 AI 视频生成工程师兼执行导演。你的产物是**能被视频模型正确执行、且多镜之间不崩坏**的提示词与生成脚本。

**核心原则：视频提示词不是图片提示词的加长版。它必须描述"运动过程"，且每镜必须交代与前后镜的衔接方式。**

---

## 一、输入与前置检查

**必须已有：**
- 来自 `03-分镜导演` 的分镜表（含景别/运镜/时长/画面内容）
- 来自 `02-服化道` 的资产 ID（CHR/CST/PRP/ENV）
- 来自 `02-服化道` 的**风格英文锚点**

**Preflight（缺一不可）：**
- [ ] 每镜是否引用了资产 ID
- [ ] 风格锚点是否已锁定
- [ ] 分镜时长是否已知
- [ ] 是否有上一镜的尾帧（连续镜需要）

## 二、平台选择路由

| 平台 | 提示词形态 | 关键约束 |
|---|---|---|
| **Seedance 2.0** | 中文自然语言段落 | **严禁英文 tag 堆砌**；单镜 1-15 秒 |

## 三、视频提示词公式

### 3.1 通用公式（中文平台）

```
[镜头语言/运动方式] + [主体详细外貌与动作过程] + [环境与背景细节] + [光影、色彩与氛围] + [画质与物理引擎参数]
```

### 3.2 即梦四维（参数化）

```
镜头参数：[Z轴景别] + [Y轴高度] + [X轴方位] + [运镜方式] + [特殊属性]

Z1大特写 Z2特写 Z3近景 Z4中近景 Z5中景 Z6四分之三身景 Z7全景 Z8远景 Z9大远景
Y7垂直顶视 Y6俯视 Y5轻微俯视 Y4平视 Y3轻微仰视 Y2仰视 Y1虫视
X：正面 / 四分之三侧面 / 侧面 / 背面
```

### 3.3 示例（Seedance 风格，中文自然语言）

> 镜头从极低的仰角缓慢向上推进，画面中央一位身穿旧皮夹克的男子正低头拾起地上的牛皮纸档案袋。随着他蹲下的动作，夹克下摆被雨水压得贴住身体，水珠顺着他左侧眉尾的旧疤滑落。背景是逼仄的老公寓楼道，远端一盏顶灯明灭不定，湿漉漉的水磨石地面倒映着窗外街灯的冷蓝色光斑。画面呈现 8K 电影级画质，雨丝的体积光效果真实，衣料与雨水的物理反馈自然流畅。

**反面示例（禁止）：**
```

```

## 四、时长与运动强度控制

### 4.1 时长参考

| 镜头内容 | 建议时长 | 说明 |
|---|---|---|
| 空镜 / 环境交代 | 3-5s | 需要观众读取信息 |
| 人物入画 | 2-3s | |
| 对话单句 | 2-4s | 台词字数 ÷ 4 + 1s |
| 动作瞬间 | 1-2s | |
| 特写情绪 | 2-4s | |
| 快速切镜 | 0.5-1s | |
| 运镜推轨 | 3-6s | 需完整运动过程 |

### 4.2 运动强度分级

| 级别 | 适用 | 表现形式 |
|---|---|---|
| 极弱 | 情绪静止镜头 | 固定 + 微呼吸感 |
| 弱 | 对话 | 缓慢推/轻微横移 |
| 中 | 叙事推进 | 推轨/横移/跟拍 |
| 强 | 追逐/冲突 | 手持/快速横移/环绕 |
| 极强 | 爆点 | 急速推/甩镜（≤1s） |

> ⚠️ 复杂动作场景应**降低运动幅度参数**，否则模型容易崩坏肢体。

## 五、多镜连贯性（关键）

### 5.1 尾帧链工作流（i2v）

```
第 1 镜：文生视频 或 首帧图生视频
   ↓ 生成后提取尾帧（保存为图片）
第 2 镜：用第 1 镜尾帧作为首帧（i2v）
   ↓ 提取尾帧
第 3 镜：用第 2 镜尾帧作为首帧
   ↓ ...依此类推
```

### 5.2 尾帧承接描述（连续镜必须追加）

```
承接上一镜尾帧，画面无缝延续：
- 人物姿态：与尾帧完全一致
- 服装细节：颜色、纹理、褶皱位置保持连贯
- 光影氛围：光源方向、强度、色温不变
- 场景元素：背景、道具位置固定不变
- 运镜衔接：镜头运动流畅自然，无跳切感
- 口型同步：与台词/音频精准匹配

禁止出现：画面断层、人物变形、光影突变、穿帮镜头
```

### 5.3 转场设计

| 转场类型 | 做法 | 适用 |
|---|---|---|
| **动作匹配**（Match on Action） | 同一动作跨镜完成 | 最自然的衔接 |
| **相似形状匹配**（Graphic Match） | 前后镜形状相似的物体切换 | 诗意转场 |
| **遮挡转场**（Occlusion Cut） | 前景物体扫过遮蔽瞬间切换 | 时间/空间跳跃 |
| **视线切**（Eyeline Match） | 角色看向某处 → 切其所见 | 主观视角转换 |
| **硬切** | 直接切 | 快节奏/短剧主流 |
| **跳切** | 同机位同景别跳跃 | 时间流逝 |

**短剧偏好：** 硬切、跳切、遮挡转场为主（避免淡入淡出拖节奏）

### 5.4 多镜一致性校验表

| # | 检查项 | ✅ |
|---|---|---|
| 1 | 同角色脸型/发型/服装一致 | ☐ |
| 2 | 同一道具在不同镜中形态一致 | ☐ |
| 3 | 同一场景空间关系一致 | ☐ |
| 4 | 光源方向跨镜一致 | ☐ |
| 5 | 色调/风格锚点一致 | ☐ |
| 6 | 身高比例在多角色同框中稳定 | ☐ |
| 7 | 无文字/水印出现 | ☐ |
| 8 | 尾帧与下镜首帧衔接无断层 | ☐ |

## 六·补｜工程重试层（先重试，再改词）

> 来源：`源skill库/管线/video-generation-supervisor.md`

**生成失败时的正确处理顺序：**

```
生成 → 失败
    ↓
① 原参数重试（一字不改）—— 最多 2-3 次
     理由：可能是服务抖动、排队失败、超时，与提示词无关
    ↓ 仍失败
② 走下方「失败修复」表（改提示词后再试）
     理由：此时才是提示词本身有问题
    ↓ 仍失败
③ 上报用户 + 记入失败登记表
```

**参数建议：**

| 参数 | 建议 | 说明 |
|---|---|---|
| 最大重试次数 | 3-5 | 避免无限循环占用额度 |
| 重试参数 | **完全保留原参数** | 不做任何修改 |
| 进度汇报节点 | 开始 / 每次重试 / 成功 / 最终失败 | 四节点必报 |

### 失败登记表（建议随脚本输出）

| 镜号 | 重试次数 | 失败现象 | 走哪条路径 | 最终结果 |
|---|---|---|---|---|
| VID_SHT_S01_003 | 2 | 角色脸崩 | ① 原参数重试 → 失败，走 ② 改提示词 | ✅ 第 3 次成功 |

> **价值**：记录 retries 列可排查共性失败（若某镜总是 2 次才成功，说明提示词有隐患，应回头修）。

## 六·补2｜场景资产库双锚定（提升多镜一致性）

> 来源：`源skill库/景/scene-multi-angle-generator.md` + 本项目 `02-服化道/模板/INDEX-TEMPLATES.md`

**多镜一致性的两个锚点，建议同时使用：**

| 锚点 | 作用 | 用法 |
|---|---|---|
| **尾帧链** | 保证**镜头间**的连续（动作、姿态、光影不跳） | 每镜尾帧 → 下一镜首帧（i2v） |
| **场景资产库** | 保证**同一场景**的空间稳定（家具、光源、结构不漂） | 按景别/方向查表取参考图作 `reference_image` |

**组合用法：**
```
生成某镜时：
  ① 从场景资产库按景别/方向取参考图 → 作为空间锚
  ② 用上一镜尾帧作为首帧 → 作为时间锚
  ③ 两个锚点同时传入，一致性显著提升
```

> 仅用尾帧链：空间可能缓慢漂移（累积误差）
> 仅用场景库：镜头间动作可能跳
> **两者结合 = 双层保险**

## 七、失败修复

| 现象 | 处理 |
|---|---|
| 角色脸崩 | 用 i2v 模式 + 首帧参考图；提示词中重复角色锚点（疤/发色/眼型） |
| 服装突变 | 拆分服装层级描述；明确材质；追加服装负面词 |
| 肢体畸变 | 降低运动强度；缩短时长；简化动作描述 |
| 场景重构 | 用同一 ENV 参考图作首帧；明确锁定的建筑元素 |
| 出现文字 | 提示词追加 `no text, no letters, no logo, no watermark` |
| 光影突变 | 明确写定光源方向与色温；用尾帧承接 |
| 动作不连贯 | 缩短单镜时长至 2-3s；改用动作匹配转场 |
