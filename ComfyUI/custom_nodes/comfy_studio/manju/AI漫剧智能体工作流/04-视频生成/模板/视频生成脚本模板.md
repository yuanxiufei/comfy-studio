## 一、脚本头（每场一次）

```markdown
## 视频生成脚本｜项目《XXX》｜EP0X 第X场

**平台**：Seedance 2.0 / 可灵 / Vidu / 即梦 / Sora / Runway
**总时长**：XX.X 秒（共 X 镜）
**画幅**：16:9 横版
**风格锚点**（全片固定追加）：
  cinematic lighting, cool blue-grey palette, controlled key light, soft fill,
  subtle rim light, foreground / midground / background separation,
  photorealistic, 8k, highly detailed, film grain
**资产引用**：CHR_001 / CST_001_Wet / ENV_001 / PRP_001, PRP_002
**ID 核对**：以上 ID 均已在 `00_PROJECT/ID-REGISTRY.md` 登记，且状态 ≥ `LOCKED`
            （`RESERVED`/`DRAFT` 状态的资产拒绝出图）
**空间锚（场景资产库）**：ENV_001 参考图集 → S01(全景) S02(正) S03(侧) S04(反) S05(俯) S06(细节)
**上游来源**：03-分镜导演 分镜表 SHT_S01_001..SHT_S01_006
**下游未决项**：见 `00_PROJECT/OPEN-ISSUES.md`（涉及本次生成的项）
```

### 双锚定机制说明（本模板的核心）

防止多镜崩坏靠**两层保险**：

| 锚 | 手段 | 防什么 |
|---|---|---|
| **空间锚** | 按景别/方位查 ENV 参考图（S01-S06） | 同一空间不同镜之间**布局/建筑/家具位置漂移** |
| **时间锚** | 每镜尾帧作下一镜首帧（i2v 尾帧链） | 相邻镜之间**人物/光影/动作断层** |

> **只做时间锚不够**：跨场景或打断尾帧链时，时间锚失效，必须靠空间锚兜底。

- **提示词**：
  > ...
- **转场衔接**：承接上一镜尾帧，画面无缝延续
- **尾帧承接**（= 时间锚，标准段落，必加）：
  ```
  承接上一镜尾帧，画面无缝延续：
  - 人物姿态：与尾帧完全一致
  - 服装细节：颜色、纹理、褶皱位置保持连贯

  ```
- **音效逻辑**：脚步声与画面同步
- **生成方式**：i2v（首帧 = 上一镜尾帧）

- 转场（跨场景）时可断开链条，用转场设计衔接

### 失败处理顺序（不可颠倒）

```
生成失败
  ↓
① 原参数重试（工程层）——同一提示词、同一参数，重试 2-3 次
   理由：多数失败是服务抖动/排队超时，不是提示词问题
  ↓ 仍失败
② 改提示词再试（内容层）——见主控 §七 失败修复表
  ↓ 仍失败
③ 上报用户 + 记入失败登记表
```

> ⚠️ **先做 ① 可避免因服务问题误改提示词**——这是本项目最容易被跳过的步骤。

**失败登记：**

| 镜号 | 失败现象 | 类型 | 原参数重试次数 | 改词方案 | 重生成结果 |
|---|---|---|---|---|---|
| | 角色脸崩 / 服装突变 / 肢体畸变 / 场景重构 / 出现文字 / 光影突变 / 动作不连贯 | | /3 | 见主控 §七 | ☐ |

## 四·补、跨场景镜头的空间锚处理

尾帧链在**跨场景**处必然断裂，此时**不能靠时间锚，只能靠空间锚**：

| 情况 | 时间锚（尾帧链） | 空间锚（ENV 参考图） | 做法 |
|---|---|---|---|
| 同场景连续镜 | ✅ 可用 | ✅ 辅助 | 尾帧承接为主 |
| 跨场景切换 | ❌ 断裂 | ✅ **主力** | 新场景首镜**不带尾帧承接**，改为按 ENV 参考图 S 编号重建空间 |
| 同场景但跳时间 | ⚠️ 视情况 | ✅ **主力** | 空间布局锁死，只允许灯光/天气/道具变化 |
| 插入空镜/特写 | ⚠️ 视情况 | ✅ 辅助 | 空镜不必承接，但空间关系须一致 |

**跨场景首镜的提示词写法：**

```
（不写"承接上一镜尾帧"）
改为写明：
- 空间依据：ENV_00X ／ S0N 视角
- 空间要素固定：建筑结构、门窗位置、家具摆放、地面材质、主空间关系
- 允许变化：天气、时间、人物、灯光状态、道具摆放
```
