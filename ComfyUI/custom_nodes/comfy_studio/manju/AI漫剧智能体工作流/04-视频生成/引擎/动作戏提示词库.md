## 一、本库的核心价值：「视觉手法」被命名了

源素材最独特的地方：**每条都把「怎么拍出打击感」抽象成了一个可复用的手法名**。

```text
结构： [场景 + 人物 + 核心动作] 。+ [视觉手法关键词组]
                 ↑ 可替换                              ↑ 本库要提炼的部分

例：雨中擂台，两名壮汉极速近身格斗，左勾拳击中下颌。
    。拳拳到肉的打击感｜骨骼发力｜肌肉紧绷｜汗水飞溅的微距特写｜高速摄影机慢动作
      └────────────── 这 5 个手法词组，可以搬到任何一场近身战 ──────────────┘
```

**手法与场景解耦**：把「拳拳到肉的打击感」那组手法，套到「法术对轰」的场景上也成立。
所以本库按**手法**归类，不按场景归类。

## 三、从 12 条提炼的通用规律

### 3.1 每条都靠「三件套」立住

| 件 | 作用 | 例 |
|---|---|---|
| **① 物理真实细节** | 让动作"重"起来 | 骨骼发力 / 地面龟裂 / 反作用力弹射 / 金属碰撞的火花 |
| **② 一个夸张的视觉母题** | 让人记住这一场 | 泼墨 / 残影 / 气浪 / 弹幕 / 巨物阴影 |
| **③ 摄影机声明** | 决定观感 | 微距特写 / 高速慢动作 / 长镜头跟随 / 手持剧烈摇晃 / 第一人称 / 低角度仰拍 |

> **只写①②不写③** = 提示词里没有"怎么拍"，模型会给你一个平庸的中景。

### 3.2 摄影机手法速查（按意图）

| 意图 | 手法 | 出处 |
|---|---|---|
| 强化**冲击力与痛感** | 微距特写 + 高速慢动作 | #1 |
| 强化**速度与流畅** | 长镜头跟随 + 背景动态模糊 | #3 |
| 强化**真实与混乱** | 手持剧烈摇晃 + 伪纪录片质感 | #9 |
| 强化**压迫与代入** | 第一人称 + 滤镜（夜视幽绿） | #8 |
| 强化**体型差距** | 低角度仰拍 + 极大比例反差 | #10 |
| 强化**失重与非常规** | 零重力物理规律 + 反作用力弹射 | #11 |

### 3.3 场景可替换性验证

同一组手法换个场景仍然成立——**这是本库能"复用"的关键**：

```text
「拳拳到肉的打击感 + 微距特写 + 高速慢动作」那组手法：
  雨中擂台（原） → 未来机甲舱内 → 古罗马角斗场 → 校园地下室
  ✅ 场景全换，手法照用

「泼墨式的动作张力 + 留白 + 黑白高对比」那组手法：
  黑衣剑客（原） → 水墨山水中两位剑修 → 书法化剑招
  ✅ 风格化手法与题材强绑定，但可横向扩展到同类"东方美学"题材
```

### ⚠️ 合规预警（必读）

本库 **12 条中有 6 条含暴力元素**，是发布前最容易被限的区域：

| 风险条目 | 风险点 | 过审建议（见 `06-合规审核` 过审八法） |
|---|---|---|
| #1 打击感 | 汗水/力量感，相对安全 | 可用 |
| #9 写实暴力 | **血滴飞溅 + 连续砸拳** | 🔴 高风险 → 用「侧写化」（改为反应镜头）/「抽象化」（血→暗色痕迹） |
| #2 刀光剑影 | 冷兵器对砍 | 🟡 用「状态化」（刀刃相击的火花，不表现伤人） |
| #4 水墨 | 已用墨汁替代血液 | ✅ **本身即为过审示范**——"浓重墨汁在空中炸开"替代血 |
| #5 枪战 | 枪械 + 射击 | 🟡 平台对枪械敏感，需核实目标平台规则 |
| #7 法术对轰 | 相对安全（非现实暴力） | 可用，注意"死伤"表述 |

> **正向案例**：#4 水墨风是**天然过审的暴力美学**——用"墨汁"替代"血液"、用"留白"替代"血腥"、
> 用"泼墨张力"替代"伤害描写"。**动作戏合规的最优路径是风格化，而非删减。**
