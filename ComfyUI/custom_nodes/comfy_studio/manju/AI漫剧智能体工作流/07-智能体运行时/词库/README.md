# 词库/ —— 可再生的**数据文件**（不是代码）

> ⚠️ 本目录**不能改名叫 `data/`**：仓库根的 `.gitignore` 有一行 `data/`
> （为根目录那 4.3 GB 用户素材设的，且**没有锚定**），会连带忽略**任何层级**的
> `data/`。后果很隐蔽 —— 词典不入库，而且将来往该目录加文件也会**静默不入库**。
> 故用项目自己的中文目录名（与 `工具/` 一致）。

## `zh2en.json.gz` 是什么

「**中文词 → 英文**」词典，供 `src/prompt_engine.tr()` 作为**外挂层**查用
（gzip 压缩的 JSON，61,880 条，约 600 KB）。

它解决的问题：`tr()` 原来只有**手写 168 条**（`ZH2EN`）+ 职业 43 条
（`OCCUPATION_EN`）。手写的根本问题不是"少"，而是**它变成了一道闸门** ——
查不到的词进不了英文提示词，于是「任何一部小说都行」这条要求，
实际被"我们手写了多少词"卡住。

**实测收益**（用压缺口的用例，统计「因译不出而被丢掉的字段」）：

| | 丢掉字段数 |
|---|---|
| 只有内置 | 9 |
| **装上外挂** | **2** |

丢掉的是例如 `线人 / 巡捕 / 掌柜 / 船工 / 厅 / 弄堂阁楼` —— 全是**表外题材**的词。

## 怎么重新生成（可复现）

```bash
python 工具/生成词库.py                 # 自动下载 CC-CEDICT（约 4 MB）
python 工具/生成词库.py --源 cedict.txt  # 用本地文件（推荐）
python 工具/生成词库.py --预览           # 只看统计与样例，不写文件
```

生成脚本里每条清洗规则都写了**为什么**（都是实测踩到的：
分隔符不止 `/` 还有 `;`、义项要逐个试而不是只取第 1 个、括号注记要剥掉、
含中文要截断、专有名词靠"拼音首字母大写"这个结构信号排除……）。

## 两层词表的设计（**内置优先**）

| 层 | 来源 | 职责 | 优先级 |
|---|---|---|---|
| ① 内置 | `prompt_engine.ZH2EN`（手工） | **为 prompt 调过的措辞** | ✅ 优先 |
| ② 外挂 | 本目录的 `zh2en.json.gz` | **广度**：只补内置没有的词 | 兜底 |

**内置必须优先**：否则手工调好的措辞（`义肢 → prosthetic limb`、
`军装 → military fatigues`、`亚麻 → linen`）会被词典里的通用译法
（`artificial limb` / `military uniform` / `flax`）顶掉。

## 已知边界（诚实说明）

- **词典是"词条级"的，不是"短语级"**：`旗袍 → cheongsam` 查得到，
  但「破损军用风衣」这种组合仍由代码拼装 —— 拼装逻辑才是本项目的价值。
- **义项可能不匹配**：CC-CEDICT 是通用词典，`皮质` 的第一个义项是解剖学的
  `cortex` 而不是 `leather`。这类**高频领域词**应补进**内置层**（那正是内置层的用途）。
- **专有名词过滤会误伤**：靠"拼音首字母大写"排除人名/地名，因此
  `道长`（`Dao4 Zhang3`）这类**带专名性质的职衔**也一并被排除。
- **词典本身没有的词**：`舞女`、`城隍庙` 等查不到，只能靠内置层或 LLM 补。

> 删掉本文件也不会报错 —— 外挂层是**可选**的，没有它一切照常跑（只是覆盖变窄）。
> `python main.py doctor` 会显示当前用的是哪一层。
