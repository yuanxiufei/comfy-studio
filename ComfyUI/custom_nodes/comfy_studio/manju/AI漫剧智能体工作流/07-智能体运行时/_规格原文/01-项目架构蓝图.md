# AI漫剧资产库 Agent

## Version

2.0.0

## Project Goal

构建一个可以在 CodeBuddy 中持续运行、跨电脑迁移的 AI 漫剧视觉资产生产 Agent。

核心流程：

```text
用户自然语言
    ↓
Agent 意图识别
    ↓
资产类型识别
    ↓
角色/道具/服装结构化
    ↓
自动补全视觉设定
    ↓
生成标准资产规格
    ↓
生成 Image Prompt
    ↓
调用图像生成模型
    ↓
保存图片
    ↓
保存 Prompt / JSON / 元数据
    ↓
形成可复用资产库
```

# 二、核心 Agent

整个系统建议拆成 6 个逻辑 Agent。

## 1. Router Agent

负责判断用户想做什么。

输入：

```text
帮我设计一个废土女佣兵
```

输出：

```text
asset_type = character
operation = create
```

如果：

```text
把她的头发换成银色
```

输出：

```text
asset_type = character
operation = modify
target = previous_character
change = hair_color
```

如果：

```text
设计她腰上的枪
```

输出：

```text
asset_type = prop
operation = create
relation = character_equipment
```

```json
  "name": "",

  "gender": "female",

  "appearance": {},
  "body": {},
  "hair": {},
  "face": {},
  "clothing": {},
  "equipment": [],
  "color_palette": {},
  "materials": {},
  "style": {},
  "pose": {},
  "three_view": {}
}
```

# 四、Prop Agent

负责：

- 武器
- 工具
- 医疗设备
- 机械装置
- 科幻设备
- 日用品
- 载具部件
- 饰品

同样生成唯一：

```text
PROP-001
PROP-002
PROP-003
```

---

# 五、Costume Agent

服装独立资产化。

例如：

```text
COSTUME-001
```

可以绑定：

```text
CHAR-001
```

以后用户说：

> 给 CHAR-001 换成 COSTUME-002

就可以快速进行角色换装。

---

# 六、Consistency Agent

这是整个系统非常重要的一层。

它负责检查：

```text
脸是否一致
发型是否一致
年龄是否一致
体型是否一致
服装是否一致
装备是否一致
颜色是否一致
材质是否一致
```

如果用户只是：

> 改发色

Consistency Agent 必须确保：

```text
Face = unchanged
Body = unchanged
Clothing = unchanged
Equipment = unchanged
```

只修改：

```text
Hair Color
```

---

# 七、Prompt Agent

Prompt Agent 不负责创造人物本身。

它负责把结构化数据转换成：

```text
Image Prompt
Negative Prompt
Layout Prompt
Consistency Prompt
```

最终组合：

```text
MASTER PROMPT
```

# 十、版本控制

修改角色时不要覆盖原始资产。

例如：

```text
CHAR-001
CHAR-001-v002
CHAR-001-v003
```

用户：

> 给她增加机械右腿

生成：

```text
CHAR-001-v002
```

原来的：

```text
CHAR-001-v001
```

保留。

# 十三、Metadata

同时保存：

```text
CHAR-001.json
```

记录：

- 创建时间
- 修改时间
- Prompt
- Negative Prompt
- 模型
- 分辨率
- 风格
- 版本
- 输入描述
- 角色设定

这样以后换模型仍然可以重新生成。

# 二十、跨电脑迁移

完整项目：

```text
AI漫剧资产库Agent/
```

可以整体复制。

如果使用 Git，也可以：

```text
电脑 A
↓
Git Repository
↓
电脑 B
↓
Clone
↓
恢复 Agent
```

API Key 不应放进 Git。

应该使用：

```text
.env
```

并加入：

```text
.gitignore
```
