# 配音单 · EP01

> **本文件管什么**：把 `对白表_EP01.md` 的台词**按角色归并成配音工单** ——
> 一条 `AUD_VO_*` 一行，交 05 去产配音。
>
> 字段的**专业口径**（声线九要素 / 气息 / 颗粒感 / 空间与收音）不在本文件，
> 在 **05 音乐音频模块的《声音设计引擎》**。本文件只保证**输入结构化**：
> 谁、说什么、什么情绪、哪个空间。

---

## 一、配音条目

| 音频 ID | 角色 | 台词范围（镜号） | 情绪线 | 语速 / 停顿 | 空间与收音 | 备注 |
|---|---|---|---|---|---|---|
| AUD_VO_EP01_001 | | SHT_…_001–005 | | | | |
| AUD_VO_EP01_002 | | | | | | |

**字段口径**：

| 字段 | 怎么填 |
|---|---|
| 音频 ID | `AUD_VO_<集>_<序号>`；**先在本表提名，再交给 05 产出** |
| 角色 | ID（`CHR_001`）；同一角色一集可拆多条（不同空间/不同情绪） |
| 台词范围 | 镜号区间，必须能在对白表里逐条对上 |
| 情绪线 | 本条的**走向**（如：从隐忍到破防），不是单点情绪 —— 配音要的是曲线 |
| 语速 / 停顿 | 关联对白表 §二 的档位；特殊停顿单独标（如"这里停 1 秒"） |
| 空间与收音 | 室内/室外、混响大小、是否贴身收（决定 05 加什么空间感） |

---

## 二、跨集一致性（**同一个角色，同一副嗓子**）

| 项 | 要求 |
|---|---|
| 声线 | 全剧固定；**一旦定稿写进本表并锁定**，后续集只引用不重定 |
| 年龄感 / 气息 | 同一个角色跨集不得漂移（这是"听起来不像同一部剧"的主要原因） |
| 特殊状态 | 受伤 / 隔着门 / 电话里 → **在备注里写清**，由 05 决定处理方式，**不要另起一个声线** |

> ⚠️ **别为"这一集情绪不同"换声线** —— 换的是**表演**（语速/气息/停顿），
> 不是**音色**。换音色等于换人，观众立刻察觉。
