# 项目目录规范（唯一权威）

> **本文件管什么**：一个项目目录里**每一层放什么、谁来写、谁来读、文件怎么命名**。
>
> **迭代历史**：本文件由两处收敛而来 —— `02-服化道/项目骨架/README.md` §一（资产目录）
> 与 `生产流程规范（S0-S7）.md` §七（`00_PROJECT/` 五段）。
> 那两处已改为指向本文件；**目录相关冲突一律以本文件为准**。
>
> 2026-09-27 再进一步：`02-服化道/项目骨架/AI_DRAMA_PROJECT/`（那份实体骨架）
> **已删除** —— 它与 `python main.py project new` 生成的东西重复，且已漂移
> （副本里缺 `06_对白/` 与 `11_AUDIO/`）。实体目录**只由命令生成**，
> `工具/校验.py` 有一条机械规则防它长回来。
>
> ⚠️ **不写死机器路径**：下文所有 `<项目名>` 都指运行时探测到的 `projects/<项目名>/`
> （`VOIDE_PROJECTS_ROOT` 优先）。

## 三、为什么这么分（两条判据，不是审美）

| 判据 | 体现 |
|---|---|
| **① 按「谁产出」分段，不按「文件类型」分段** | `00_PROJECT/` 是**跨模块**的流程与台账；资产段是 02 的；生产段是 03/04/05/06 的。按类型分（"所有图片放 images/“）会让**每集都要翻遍全库** |
| **② 「文本台账」与「二进制产物」分开** | `06_对白/`（编排方案，文本）与 `11_AUDIO/`（音频文件）分开 —— 前者要评审、要改、要 diff，后者是产物。混在一处会让 `git diff` 失去价值 |

**为什么 `09_SHOTS/` 与 `11_AUDIO/` 不在 `00_PROJECT/` 里**：
`00_PROJECT/` 的定位是**过程资料与账**（可评审、体量小）；
成片产物按阶段平铺在顶层，与 `08_STORYBOARDS/` 同级，便于按阶段整包交付。

## 四、一个项目从零到有

```bash
cd AI漫剧智能体工作流/07-智能体运行时
python main.py project new 我的剧      # 建目录 + 入口文件 + 填 03_台账/ 的空表
python main.py project check 我的剧    # 随时查：缺哪个落点、哪阶段还没产物
```

**填充顺序**（与 S0–S7 一致，详见 `流程与落点映射.md`）：

1. `00_PROJECT/07_素材归档/素材来源登记.md` —— **先登记原著与授权**（改编权是 BLOCKING 项）
2. `novel/*.txt`（工作区级）→ S0 产出 `00_PROJECT/01_剧本/`
3. `00_PROJECT/03_台账/` 两张表随 S0 一起建，之后**每个模块交付都要回填**
4. S1 起按 `流程与落点映射.md` 逐阶段推进，每阶段产物落在上表对应目录

## 五、命名通则

| 对象 | 约定 | 例 |
|---|---|---|
| 集号 | `EP` + 两位 | `EP01` |
| 分集产物 | 集号做**前缀**，便于排序 | `EP01-剧本.md`、`对白表_EP01.md` |
| 交付包 | `<上游编号>到<下游编号>` | `交付包-01到02.md` |
| 版本 | 改已定资产 → `_v2`，**不覆盖 `_v1`** | `CHR_002_v2_front.png` |
| 一集一目录 | 分镜帧、视频、音频按集分目录 | `frames_EP01/`、`09_SHOTS/EP01/` |

> ⚠️ **集号必做前缀而不是后缀**（`EP01-剧本.md` 而不是 `剧本-EP01.md`）：
> 资源管理器与 `ls` 默认按名排序，前缀才排得整齐。

## 六、边界（诚实说明）

| 项 | 状态 |
|---|---|
| 目录清单与规范一致性 | ✅ 由 `tests/test_project.py` 机械核对（`src/project.py` 的 `PROJECT_DIRS` ↔ 本文件） |
| 「哪一阶段还没产物」体检 | ✅ `project check` |
| **项目目录内的 ID 漂移检测** | ❌ 未实现 —— `drift` 扫的是 07 运行时的资产库，**默认不扫项目目录**（要让机器校验项目目录，需先把资产导入运行时，那是另一个决策，**不要默认做**） |
| 「产物内容合不合格」 | ❌ 不做 —— 那是各模块**门禁**的职责（`python main.py gate <模块> <文件>`） |
