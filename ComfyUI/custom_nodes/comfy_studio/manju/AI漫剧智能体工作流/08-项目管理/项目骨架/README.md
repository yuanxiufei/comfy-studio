# 项目骨架 · 怎么建一个新项目

> **本目录不存实体目录树** —— 实体骨架由 `07-智能体运行时` **按规范生成**，
> 规范见上一级的 `项目目录规范.md`。
>
> ⚠️ 为什么不手工复制：手工复制会出现「复制的是上一版骨架」——
> 这正是本仓库第一号坑（改权威层忘同步实体层）。**生成的骨架永远等于规范**，
> 且 `tests/test_project.py` 会核对两者一致。

---

## 一、建一个新项目

```bash
cd AI漫剧智能体工作流/07-智能体运行时

# ① 建（在 projects/ 下，项目根由运行时动态探测）
python main.py project new 渡魂天尊 --集数 40

# ② 体检（缺哪个落点 / 哪一阶段还没产物）
python main.py project check 渡魂天尊

# ③ 看有哪些项目
python main.py project list
```

生成物：

```text
projects/渡魂天尊/
├── README.md                    项目总览（含集数、创建时间、下一步）
├── 00_PROJECT/
│   ├── 00_先读我.md
│   ├── 01_剧本/                 ← 分集正文（EP##-剧本.md）
│   │   └── 00_总纲/             ← 全剧级：大纲、角色小传
│   ├── 02_资产索引/  03_台账/
│   ├── 04_交付与出图/  05_流程/
│   ├── 06_对白/  07_素材归档/
└── 01_WORLD/ … 07_POSES/  08_STORYBOARDS/  09_SHOTS/  10_CONSISTENCY/  11_AUDIO/
```

`03_台账/`、`05_流程/`、`06_对白/`、`07_素材归档/` 里会**预置空的表头文件**
（模板来自上一级的 `模板/`），空目录会放 `.gitkeep` 以便入库。

> **幂等**：重复跑不会覆盖任何已存在的文件；要补新增落点用
> `python main.py project new <项目名> --升级`（同样不覆盖）。

## 二、建完先做三件事（顺序不能反）

| 顺序 | 做什么 | 为什么 |
|---|---|---|
| 1 | 填 `00_PROJECT/07_素材归档/素材来源登记.md` | 原著授权是 **BLOCKING** 项，它决定这片子能不能做 |
| 2 | 把原著放进工作区的 `novel/`，跑 S0 建纲 | 后面所有阶段都吃 S0 的产物 |
| 3 | 核对 `03_台账/` 两张表 | 号段冲突与未决项**拖到后面才发现**，代价最高 |

## 三、与 `02-服化道/项目骨架/` 的关系

| 那份 | 这份 / 规范 |
|---|---|
| 讲**资产目录的字段级细节**（`ASSET_CARD.yaml` 从哪个模板来、`id_status` 状态机、初始化步骤） | 讲**全景目录与流程落点**（含 `06_对白/`、`07_素材归档/`、`11_AUDIO/`） |

**冲突时以 `项目目录规范.md` 为准**（它是目录相关的唯一权威）。
两者**不重复**：一份管"目录放什么"，一份管"资产卡怎么填"。

---

## 四、已有项目怎么升级

老项目缺 `06_对白/`、`07_素材归档/`、`11_AUDIO/` 三个落点：

```bash
python main.py project new 老项目名 --升级
```

只**补缺的目录与空表**，不动任何已有文件 —— 所以对在产项目是安全的。
跑完再 `project check` 确认没有 `⚠️ 缺` 项。
