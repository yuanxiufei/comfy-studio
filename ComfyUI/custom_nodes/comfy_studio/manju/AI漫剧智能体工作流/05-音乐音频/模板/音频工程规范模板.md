## 三·补｜VOICE ID（角色声音身份卡）

> 来源：`01-声音设计引擎.md` §五十
> **用途**：写入 `02-服化道/模板/ASSET_CARD.yaml` 的 `fixed_features.voice`，作为角色声线的「终身固定特征」。

```text
VOICE ID

角色：CHR_001 / 姓名
Gender:                    性别感
Age:                       年龄感
Pitch:                     音高
Timbre:                    音色
Texture:                   颗粒质感
Resonance:                 共鸣位置
Breath:                    气息特征
Speech Rate:               语速
Articulation:              咬字
Emotional Baseline:        情绪基线
Recording Distance:        收音距离
Room:                      空间环境
Signature Trait:           标志性特征（如"句尾轻微下沉"）
```

**填充示例：**
```text
VOICE ID:
Male / Young Adult
Low-mid pitch
Dry rough texture
Chest resonance
Controlled breath
Slow-medium speech rate
Precise articulation
Emotionally restrained
Close microphone
Small dark room
Signature: slightly lowered sentence endings
```

### 一致性铁则

同一角色生成多个声音时，**必须保持**：
```
声线核心 · 年龄感 · 音高 · 颗粒感 · 呼吸习惯 · 咬字习惯 · 语速基准 · 空间距离
```

**只允许改变**：
```
情绪 · 台词状态 · 场景 · 动作
```

> 这与视觉模块的 `fixed_features` vs `stage_variables` **完全同构**（见 `02-服化道/引擎/LOCK-SYSTEM.md` §四·补）。
> **落地**：VOICE ID 写入 `fixed_features.voice`；各情绪/场景下的声线变化写入各 `_State_X` 卡的 `stage_variables`。

### 声线派生（对应 §51 角色声音进阶设计）

| 声线类型 | 用途 | 变化范围 |
|---|---|---|
| 核心声线 | 平时说话的基础声音 | 基准 |
| 情绪声线 | 不同情绪下的变化 | 仅情绪/语速/气息 |
| 战斗声线 | 高强度状态 | 音量/呼吸/力度 |
| 悄声声线 | 秘密交流 | 音量/距离/气声 |
| 崩溃声线 | 情绪失控 | 张力/破裂感 |
| 非人化声线 | 超自然化 | 特殊质感叠加 |

## 三·补2｜声音层级系统（10 层）

> 来源：`01-声音设计引擎.md` §五十三
> **用途**：复杂场景的声音设计拆解；也是**混音时的轨道划分依据**。

| 层 | 内容 | 对应轨道 |
|---|---|---|
| Layer 1 | 环境底噪 | AMB |
| Layer 2 | 远景声音 | AMB |
| Layer 3 | 中景声音 | AMB / SFX |
| Layer 4 | 近景声音 | SFX |
| Layer 5 | **角色对白** | VOX_MAIN |
| Layer 6 | **Foley** | SFX |
| Layer 7 | 情绪声音 | SFX / VOX |
| Layer 8 | 特殊声音设计 | SFX |
| Layer 9 | 低频氛围 | BGM / SFX |
| Layer 10 | 尾音 / Reverb Tail | 总线 |

### 电影级空间设计要素（§五十四）

```
Foreground / Midground / Background / Room Tone / Reflection /
Reverb Tail / Distant Elements / Transient Events / Silence
```

> ⚠️ **不是声音越多越好。** 用「声音密度 + 空间距离 + 静默」制造真实感。

### 静默设计（§五十七）

需要压迫感时主动使用：
```
near silence · low room tone · distant isolated sound · long pause · sudden sound cutoff
```

适合：悬疑 · 恐怖 · 心理戏 · 反派登场 · 角色死亡 · 真相揭露

### 声音动态设计（§五十五）

```
soft → louder → peak → decay
silence → subtle sound → tension → impact → silence
```

**高潮结构（§五十六）：**
```
low-frequency buildup + increasing texture density + rising pitch
+ increasing loudness + transient impact + reverb tail + sudden silence
```

## 四、调音工程规范模板

```text
【音频工程规范 AUD_ENG_EP0X】

轨道结构：
  VOX_MAIN    人声主轨
  VOX_ALT     人声副轨（旁白/电话）
  BGM         配乐轨
  SFX         音效轨
  AMB         环境轨

响度目标：
  Integrated : -14 LUFS（流媒体）
  True Peak  : ≤ -1 dBTP
  LRA        : 6-9 LU

人声链（顺序不可颠倒）：
  ① 降噪              强度 <中>
  ② 高通滤波          100 Hz
  ③ EQ                300Hz -3dB ｜ 4kHz +2dB
  ④ 压缩              4:1，阈值 -18dB，attack 5ms，release 80ms
  ⑤ 齿音消除          4-8kHz 抑制
  ⑥ 饱和/染色         轻微温暖（可选）
  ⑦ 混响              短混响 1.0s，比例 15%
  ⑧ 延迟              （仅情绪段，可选）

BGM 链：
  侧链压缩（侧链源 = VOX_MAIN，触发即降 4dB）
  EQ：低频 ≤100Hz 衰减 2dB

增益关系：
  VOX_MAIN 高于 BGM 6-10 dB
  对白段 BGM 控制在 -18 ~ -22 dB

交付格式：
  WAV 48kHz / 24bit（工程）
  AAC 320kbps（发布）
```

## 五、混音问题排查表

| 现象 | 原因 | 处理 |
|---|---|---|
| 人声被 BGM 淹没 | 动态竞争 | BGM 侧链压缩，触发降 3-6dB |
| 声音干瘪 | 缺空间感 | 加短混响 + 轻微饱和 |
| 忽大忽小 | 动态过大 | 压缩器 + 全轨音量自动化 |
| 手机外放难听 | 中频缺失、低频过多 | 2-4kHz +2~3dB，≤100Hz 衰减 |
| 高潮不炸 | 无对比 | 高潮前 2 秒整体降 2dB，高潮回升 |
| 集尾突兀 | 无尾巴 | 留 0.3-0.5s 衰减 |
| 齿音刺耳 | s 音突出 | De-Esser 4-8kHz |
| 底噪明显 | 降噪不足 | 提高降噪强度，检查录音源 |
