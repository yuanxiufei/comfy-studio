## 二、能力 A｜Suno 歌词创作（快速版）

> ⚠️ **本节是快速版**——只覆盖短剧插曲的常见场景（60-90 秒、简单结构）。
> 需要完整能力（8 大曲风族 · 7 种结构模板 · 14 个 Style 模板 · 调整指令 · 词库 · 质量自检）时，**一律转 `02-Suno歌词引擎.md`**。

**何时用快速版**：已有明确主题与曲风，只要一版 60-90 秒短剧插曲歌词。
**何时转 02 引擎**：用户只给关键词要完整歌曲 / 要「更洗脑/更高级/更燃」等调整 / 要优化 Style Prompt / 需要非短剧长度（2.5-4 min 标准流行）。

### A1. Suno 结构化语法（必须遵守）

```
[Intro]         前奏
[Verse]         主歌（叙事，铺设情境）
[Pre-Chorus]    预副歌（情绪抬升）
[Chorus]        副歌（记忆点，全曲最高能量）
[Post-Chorus]   后副歌
[Bridge]        桥段（转折/降能）
[Instrumental]  器乐段
[Outro]         尾奏
```

**风格标签（Style 字段）写法：**
```
<曲风>, <情绪>, <主要乐器>, <人声类型>, <速度感>, <制作质感>
例：cinematic pop, melancholic, piano and strings, male vocal, slow, film score production
```

**Suno 参数建议：**
| 参数 | 短剧用法 |
|---|---|
| Style | 曲风+情绪+乐器+人声，逗号分隔，≤200 字符 |
| Title | 歌名（避免敏感词） |
| Instrumental | 纯音乐 BGM 时勾选 |
| 结构标签 | 写进歌词正文里控制段落 |

### A2. 短剧歌词创作流程

1. **定主题**：从剧本提取核心情感母题（≤5 字，如"迟到的真相""回不去的家"）
2. **定人称视角**：第一人称（代入强）/ 第二人称（倾诉感）/ 第三人称（旁观）
3. **定结构**：短剧插曲通常 60-90 秒 → `Intro + Verse + Chorus + Outro`
4. **写记忆点**：副歌第一句必须是全曲最钩人的句子
5. **押韵**：主歌可松散，副歌必须严韵
6. **词汇**：口语化，避免生僻词与书面语；**避免与具体真人/作品产生关联**

### A3. 歌词输出格式

```markdown
## 《歌名》
**情绪定位**：<一句话>
**建议曲风**：<Suno Style 字段内容>
**适用位置**：EP0X 第 X 场 <进/出场>
**时长**：约 XX 秒

[Intro]
（器乐）

[Verse]
<歌词>

[Chorus]
<歌词>

[Outro]
<歌词>

**Suno 参数**
- Style: <英文风格标签>
- Instrumental: <是/否>
- 建议时长: <秒>
```

### A4. 歌词红线

- 不出现真实人名/品牌/作品名
- 不出现敏感政治、宗教、暴力、涉及色情暗示的表述
- 不使用他人已发表歌词的独特句式（避免抄袭风险）
- 短剧主题曲长度 ≤90 秒

## 三、能力 B｜BGM 配乐设计

### B1. 情绪 → 音乐映射表

| 剧情情绪 | 曲风 | 乐器 | 速度 | 参考质感 |
|---|---|---|---|---|
| 悬疑/不安 | dark ambient | 低频合成器、大提琴持续音 | 慢 60-70 | 氛围压迫，无旋律 |
| 压抑/孤独 | cinematic piano | 单音钢琴、弦乐铺底 | 慢 60-75 | 留白多 |
| 温柔/回忆 | acoustic folk | 木吉他、钢琴 | 中 80-95 | 温暖 |
| 紧张/追逐 | hybrid orchestral | 打击乐、断奏弦乐 | 快 120-140 | 节奏驱动 |
| 愤怒/爆发 | epic trailer | 铜管、鼓组 | 快 130-150 | 强烈冲击 |
| 悲伤/失去 | strings lament | 小提琴独奏、弦乐 | 极慢 50-60 | 克制 |
| 希望/转折 | uplifting orchestral | 弦乐渐强、钢琴 | 中快 100-115 | 上扬 |
| 轻松/Q版 | light jazz / ukulele | 尤克里里、拨弦贝斯 | 中 90-110 | 俏皮 |
| 浪漫/暧昧 | dream pop | 电钢琴、弱化鼓 | 中慢 70-85 | 朦胧 |

### B2. 短剧配乐结构（90 秒单集）

```
0-3s     钩子段      → 无音乐或单音效冲击（留白最重要）
3-15s    建立段      → BGM 淡入，音量 -18dB，铺垫
15-45s   推进段      → BGM 主题呈示，-15dB
45-70s   情绪高点    → BGM 全奏，-12dB，可加鼓
70-85s   收束段      → BGM 渐弱至 -20dB
85-90s   集尾钩      → 音乐骤停（留 0.5s 静音）+ 冲击音效
```

### B3. 关键技法

| 技法 | 用法 |
|---|---|
| **音乐骤停** | 高潮前一瞬停乐，制造"呼吸" |
| **提前进入** | 音乐比画面变化早 0.5-1s 进入（类似 J Cut） |
| **延后结束** | 画面切了音乐还延续（类似 L Cut） |
| **主题变形** | 同一旋律不同配器表达不同情绪（角色主题） |
| **静音设计** | 全集至少留 2 处纯静音，制造压迫 |

### B4. 角色主题（可选进阶）

主要角色各配一个 4-8 小节动机，全剧复用：
```
主角动机：<描述，如"下行三音，钢琴单音">
反派动机：<描述，如"低频半音上行">
情感动机：<描述，如"弦乐长音"]
```
每次该角色关键出场或情绪转折时变形出现。

## 五、能力 D｜调音混音

### D1. 人声处理链（顺序不可颠倒）

```
① 降噪（Noise Reduction）      去除底噪、口水音
② 高通滤波（High-Pass 80-120Hz） 去除低频轰隆
③ EQ（均衡）                    200-400Hz 减浑浊，3-5kHz 提清晰度
④ 压缩（Compressor）            3:1~4:1，阈值 -18dB，控制动态
⑤ 齿音消除（De-Esser）          4-8kHz 抑制 s 音
⑥ 饱和/染色（可选）             轻微温暖感
⑦ 混响（Reverb）                短混响 0.8-1.2s，比例 ≤20%
⑧ 延迟（Delay，可选）           仅在情绪段使用
```

### D2. 响度标准

| 用途 | 目标响度 |
|---|---|
| 流媒体（抖音/快手/B站） | **-14 LUFS**（integrated），真峰值 ≤ -1 dBTP |
| 影视投屏 | -24 LUFS |
| 人声对 BGM | 人声高于 BGM 6-10 dB |
| 对白段 BGM | -18 ~ -22 dB |

### D3. 短剧混音要点

| 问题 | 处理 |
|---|---|
| 人声被 BGM 淹没 | BGM 侧链压缩（侧链源=人声轨），触发即降 3-6dB |
| 声音干瘪 | 加短混响 + 轻微饱和 |
| 忽大忽小 | 压缩器 + 全轨音量自动化 |
| 手机外放难听 | 中高频 2-4kHz 提升 2-3dB，低频 ≤100Hz 可衰减 |
| 高潮不炸 | 高潮前 2 秒整体降 2dB，高潮时回升 |
| 集尾突兀 | 留 0.3-0.5s 衰减尾巴 |

### D4. 交接清单格式

```text
【音频工程规范 AUD_001】
总线：人声轨 / BGM 轨 / 音效轨 / 环境轨
响度目标：-14 LUFS，真峰值 -1 dBTP
人声链：降噪 → HPF 100Hz → EQ(300Hz -3dB, 4kHz +2dB) → 压缩 4:1 → De-Esser → Reverb 15%
BGM 链：侧链压缩（源=人声，触发降 4dB）→ EQ(低频减 2dB)
交付格式：WAV 48kHz/24bit
```

## 九、与声音设计引擎的协作流程（完整一集）

```
① 从 02-服化道 取角色/场景/道具资产（CHR_ / ENV_ / PRP_）
② 从 03-分镜导演 取分镜表（SHT_ 的镜号、情绪、台词、动作）
        ↓
【01 声音设计引擎】
   ├─ 为每个主要角色定 VOICE ID（写入 ASSET_CARD.fixed_features.voice）
   ├─ 为每个场景出环境声提示词（引用 ENV_ ID）
   ├─ 为关键道具出 Foley 提示词（引用 PRP_ ID）
   └─ 为关键台词出演绎设计（引用 SHT_ 镜号）
        ↓
【00 本引擎】
   ├─ 定全片配乐方案与情绪映射（对应分镜表情绪列）
   ├─ 如需主题曲/插曲 → 出歌词（Suno 格式）
   └─ 出音频工程规范（轨道/响度/处理链/交付格式）
        ↓
交接 04-视频生成（音画同步：口型对齐、音效卡点）
        ↓
后期按本引擎的调音链混音
```
