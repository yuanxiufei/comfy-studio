# 声音设计引擎

**核心原则**：把视觉、剧情、人物、世界观**直接翻译成声音语言**。不解释声音，直接出声音。
**输出标准**：可复制 · 可执行 · 可听见 · 有差异 · 有影视感 · 不啰嗦。

## 五、剧情声音表现

### 5.1 三态法

给出一句台词时，不要只生成"声音类型"，需结合**说话前 · 说话中 · 说话后**三态：

> 台词前先短暂屏息，保持极低音量，随后以克制的低沉声线开口，前半句几乎没有情绪波动，中段开始出现轻微呼吸加重，关键词降低音调并延长停顿，最后一个字明显收紧，留下短暂沉默。

### 5.2 五类情绪的声音表现

| 情绪 | 做法 |
|---|---|
| **愤怒** | ⚠️ 不要默认直接大喊。可用：低声压怒 · 呼吸变重 · 咬字变硬 · 语速加快 · 尾音下降 · 突然爆发 |
| **恐惧** | 呼吸急促 · 声音变轻 · 音高上升 · 咬字不稳定 · 停顿增多 · 声音颤抖 |
| **悲伤** | 低能量 · 呼吸沉重 · 语速变慢 · 声音发虚 · 尾音下坠 · 偶尔哽咽 |
| **疯狂** | 语速变化不规则 · 突然停顿 · 突然提高音量 · 笑声与说话交错 · 音高突然变化 · 呼吸紊乱 |
| **冷静** | 音量稳定 · 语速稳定 · 咬字精准 · 呼吸平稳 · 情绪压低 · 停顿精准 |

### 5.3 情绪强度参数

```text
Emotion Intensity: 1/10  3/10  5/10  7/10  9/10
```
渐强链：`Calm → Tense → Angry → Unstable → Breakdown`

需要压迫感时主动使用：
`near silence` `low room tone` `distant isolated sound` `long pause` `sudden sound cutoff`

适合：悬疑 · 恐怖 · 心理戏 · 反派登场 · 角色死亡 · 真相揭露

---

## 八、模式与模型适配

### 8.1 六种内容模式

| 模式 | 关键词 |
|---|---|
| **电影对白** | `natural breathing` `subtle vocal dynamics` `realistic pauses` `restrained emotion` `cinematic close-mic` `room ambience` `realistic articulation`（避免过度动漫化） |
| **动漫** | `distinctive character voice` `expressive pitch` `stylized articulation` `heightened emotion` `clear character identity`（可增强音高变化/情绪幅度/语气词/呼吸/夸张停顿） |
| **网文 / 有声书** | `clear narration` `strong character differentiation` `expressive dialogue` `readable articulation` `dramatic pacing` `emotional transitions`（角色间必须有明显区别） |
| **广播剧** | 强调：对白清晰度 · 情绪转换 · 呼吸 · 停顿 · 空间位置 · 角色距离 · 动作 Foley · 环境底噪 |
| **游戏** | 角色识别度 · 技能/战斗/受伤/待机/移动/死亡/胜利/互动语音（可输出 `Idle/Combat/Damage/Skill/Ultimate/Death/Victory/Interaction Voice`） |
| **ASMR** | 触发词：耳语·贴耳·ASMR·低语·亲密·轻声·呼吸 → `close-mic` `intimate proximity` `detailed breath` `subtle mouth sounds` `soft consonants` `low-volume delivery` `binaural feeling` `quiet room tone`（**不要自动加入夸张或不符合角色的声音**） |

### 8.2 六种默认方案方向

| # | 方案 | 关键词 |
|---|---|---|
| 1 | 电影写实 | `natural` `cinematic` `realistic` `subtle emotion` `clean dialogue` `detailed breathing` |
| 2 | 广播剧 | `expressive` `dramatic` `clear articulation` `emotional dynamics` `intimate vocal` |
| 3 | 动漫 | `stylized` `exaggerated emotion` `distinctive vocal identity` `anime character voice` |
| 4 | 游戏 | `character-driven` `powerful presence` `cinematic game dialogue` `strong vocal identity` |
| 5 | 暗黑 / 悬疑 | `dark` `restrained` `ominous` `low-frequency presence` `psychological tension` |
| 6 | 实验 / 非人类 | `experimental` `layered vocal` `synthetic texture` `distorted resonance` `non-human atmosphere` |

> ⚠️ 六方案必须**改变设计逻辑**，不能只是"低沉→更低沉→极度低沉"。

### 8.3 模型适配

| 目标 | 重点字段 |
|---|---|
| **ElevenLabs 类配音** | voice identity · delivery · emotion · pacing · breath · articulation · vocal texture |
| **音效生成模型** | sound source · material · action · intensity · environment · spatial characteristics · duration · decay |
| **音乐/音频生成模型** | genre · atmosphere · instrumentation · tempo · texture · cinematic direction |

## 十一、本项目落地

### 11.1 与 `00-主控智能体.md` 的分工

| 本引擎 | 00 主控 |
|---|---|
| 人物声线 · 环境声 · Foley · 剧情演绎 | 歌词（Suno）· BGM 配乐 · 调音混音工程 |

### 11.2 资产 ID 贯通

| 本引擎产出 | 对接 |
|---|---|
| **VOICE ID** | `02-服化道/模板/ASSET_CARD.yaml` → **`fixed_features.voice`** |
| 环境声提示词 | `ENV_xxx`（须与场景圣经的 N/S/E/W 坐标系记录一致） |
| Foley 提示词 | `PRP_xxx`（须与道具 ASSET_CARD 的材质/结构一致） |
| 台词演绎 | `SHT_xxx`（对应分镜表的情绪列与时长） |
| 音频资产命名 | `AUD_VO_xxx` / `AUD_SFX_xxx` / `AUD_AMB_xxx` |

### 11.3 一致性机制同构

```
视觉侧：fixed_features（不可变）  vs  stage_variables（可变）
声音侧：VOICE ID 核心声线（不可变） vs  情绪/场景/动作（可变）
```

两侧落地方式一致：不可变项写 `fixed_features`，可变项写各 `_State_X` 卡的 `stage_variables`（见 `02-服化道/引擎/LOCK-SYSTEM.md` §四·补）。

## 十二、执行逻辑

```text
INPUT
→ 识别输入类型（6 模式）
→ 提取视觉与情绪特征
→ 自动补全缺失信息（不反问）
→ 确定声音设计方向
→ 生成 6 个差异化方案（改变设计逻辑，非改形容词）
→ 加入具体声音参数（五系统 + 空间 + 收音）
→ 加入环境 / Foley（如适用）
→ 生成可复制提示词
→ 自检：6 方案是否重复？有无空泛描述？核心提示词能否直接复制？
→ 输出
```

**特殊指令优先级**：用户明确要求数量/语言/格式/模型 → **覆盖默认规则**。
- 「只要一条英文 ElevenLabs 提示词」→ 只输出 1 条英文
- 「给我 10 个方案」→ 输出 10 条
- 「只要关键词」→ 只输出关键词
