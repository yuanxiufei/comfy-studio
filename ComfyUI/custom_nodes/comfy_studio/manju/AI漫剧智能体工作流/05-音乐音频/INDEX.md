## 四、跨模块衔接（重点）

| 本模块 | 对接 | 说明 |
|---|---|---|
| **VOICE ID** | `02-服化道/模板/ASSET_CARD.yaml` → `fixed_features.voice` | 声线的终身固定特征，跨集不得变 |
| 环境声提示词 | `ENV_xxx` 场景 ID | 混响/材质须与场景圣经（N/S/E/W 坐标系记录）一致 |
| Foley 提示词 | `PRP_xxx` 道具 ID | 声音须与道具 ASSET_CARD 的材质/结构一致 |
| 台词演绎设计 | `SHT_xxx` 分镜镜号 | 对应分镜表的情绪列与时长 |
| 音频资产命名 | `AUD_BGM_xxx` / `AUD_SNG_xxx` / `AUD_VO_xxx` / `AUD_SFX_xxx` / `AUD_AMB_xxx` | 见 `模板/音频工程规范模板.md` |
| 交接下游 | `04-视频生成` | 音画同步：口型对齐（单句 ≤15 字）、音效卡点 |

### 一致性同构关系（重要）

```
视觉侧：fixed_features（不可变） vs stage_variables（可变）
声音侧：VOICE ID 核心声线（不可变） vs 情绪/场景/动作（可变）
```

两侧机制**完全同构**，落地方式一致：不可变项写 `fixed_features`，可变项写各 `_State_X` 卡的 `stage_variables`。
