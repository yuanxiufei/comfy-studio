## 关键衔接点（资产 ID 贯通）

| 本模块产出 | 引用/对接 | 说明 |
|---|---|---|
| **VOICE ID** | `02-服化道/模板/ASSET_CARD.yaml` 的 **`fixed_features.voice`** | 声线的「终身固定特征」——与角色固定特征库同源，跨集不得变 |
| **Foley 提示词** | `PRP_xxx` 道具 ID | 每个道具的声音必须与其 ASSET_CARD 的材质/结构一致 |
| **环境声提示词** | `ENV_xxx` 场景 ID | 混响与材质必须与场景圣经（N/S/E/W 坐标系记录）一致 |
| **配音情绪强度** | `SHT_xxx` 分镜镜号 | 对应分镜表的情绪列 |
| **主题曲 Hook** | `SHT_xxx` 核心视觉镜 | 歌词 Hook 应对齐剧情核心意象（如《雨夜归人》的「21:47」= 怀表镜） |
| **主题曲人声** | `AUD_VO_xxx` 角色声线 | Style 里的 vocal 描述须与角色声线设定一致（不写「女声」而角色是男声） |
| **音频资产** | `AUD_xxx` 命名 | 见 `模板/音频工程规范模板.md` |

### 一致性铁则（与视觉模块同源）

01 引擎的核心一致性机制「**只改变情绪/台词/场景/动作，不变声线/年龄感/音高/颗粒/呼吸习惯/咬字/语速基准/空间距离**」，
与 `02-服化道/引擎/LOCK-SYSTEM.md` 的 `fixed_features` vs `stage_variables` **完全同构**。

**落地方式**：把 VOICE ID 写入 ASSET_CARD 的 `fixed_features.voice`，把「不同情绪下的声线」写入各 `_State_X` 卡的 `stage_variables`。

## 关键技术参数速查

| 项 | 标准 |
|---|---|
| 流媒体响度 | `-14 LUFS` integrated，真峰值 ≤ `-1 dBTP` |
| 影视投屏响度 | `-24 LUFS` |
| 人声对 BGM 增益 | 人声高 6-10 dB |
| 对白段 BGM | `-18 ~ -22 dB` |
| 混响比例 | ≤ 20%，短混响 0.8-1.2s |
| 单句台词长度 | ≤ 15 字（便于口型对齐） |
| 语速基准 | 4-5 字/秒 |
| 声音层级 | 10 层（底噪→远景→中景→近景→对白→Foley→情绪声→特殊设计→低频氛围→尾音） |
