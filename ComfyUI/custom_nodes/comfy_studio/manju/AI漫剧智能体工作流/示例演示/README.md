# 端到端示例 · 一句话创意 → 可发布单集

> 用一句话创意，走通全部六个模块，展示**每次交接的真实产物形态**。
> 用途：① 验证六模块能否顺滑衔接 ② 作为实际操作参照
> 项目：《雨夜归人》EP01（承接 `02-服化道/示例演示/` 的资产设定）

---

## 起点

> **用户一句话**：「一个刑警在雨夜的旧楼里捡到父亲留下的怀表，指针停在他父亲遇害的那一刻。」

---

## 走通链路

```
【输入】一句话创意
   ↓ 总控路由判定：进入 01 剧本模块（路线 A 从零建纲）
【01 剧本文本】
   产出：EP03 剧本 + 角色小传 + 分集大纲 + 三表
   ↓ 交接包 ①
【02 服化道】
   产出：VISUAL_BIBLE + 角色三视图 + 服装 + 道具 + 场景 + 风格锚点
   ↓ 交接包 ②
【03 分镜导演】
   产出：EP01 九列分镜表 + 每镜 AI 提示词
   ↓ 交接包 ③
【04 视频生成】
   产出：视频生成脚本 + 尾帧链
   ↓ 交接包 ④
【05 音乐音频】
   产出：EP01 配乐结构 + 配音规范 + 音频工程规范
   ↓ 交接包 ⑤
【06 合规审核】
   产出：风险扫描 + 过审优化 + 发布前检查
   ↓
【输出】可发布 EP01
```

## 关键验证点

| # | 验证项 | 关注什么 |
|---|---|---|
| 1 | 路由判定准不准 | 总控能否从"一句话创意"正确进入 05 |
| 2 | 角色小传够不够下游用 | 05 输出的外貌要点能否直接喂给 02 |
| 3 | ID 是否贯通 | `CHR_001` 从 05 一路传到 06 不换名 |
| 4 | 风格锚点是否锁定 | 02 定的锚点在 03/04 是否原样追加 |
| 5 | 三门禁是否生效 | 每阶段交接前是否校验 |
| 6 | 情绪基调是否跨模块一致 | 02 的冷蓝灰 ↔ 01 的影调 ↔ 04 的配乐情绪 ↔ 06 的风险点 |
