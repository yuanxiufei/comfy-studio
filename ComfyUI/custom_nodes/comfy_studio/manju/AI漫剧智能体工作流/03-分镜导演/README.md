## 二、三个主文件怎么选（两个引擎，范式不同）

| 文件 | 范式 | 产物 | 何时用 |
|---|---|---|---|
| **`分镜导演-完整合并版.md`** | 同叙事分镜 | 主工作流 + 10 套源 skill 全文，单文件自包含 | **部署到 GPTs/Coze/Dify 首选** |
| `主工作流/storyboard-director-pro.md` | **先表后词** | **九列分镜表**（景别/运镜/画面/台词/音效/**时长/转场**/提示词） | 要**投产分镜表**、对接 `04-视频生成`、需要时长与转场 |
| **`视觉分镜引擎.md`** | **先图后拆** | **三部分**：Frame 视觉序列 / Shot 拆解 / 中英 Prompt | 要**看画面、出图、定视觉**，对接 MJ/SDXL/Flux |

### 选择判据

```
「这段戏怎么拍、每镜几秒、怎么转场」   → 叙事分镜引擎（storyboard-director-pro）
「这段戏看起来是什么样、出图给我」     → 视觉分镜引擎
两者都要（完整一集）                   → 先用视觉分镜引擎定视觉，再用叙事分镜引擎出表
```

### 两个引擎的关键差异

| 维度 | 叙事分镜引擎 | 视觉分镜引擎 |
|---|---|---|
| 默认镜头数 | 按剧本节奏推 | **固定 9**（可由用户改） |
| 时长 / 转场 / 音效 | ✅ 有（九列表） | ❌ 无（视觉设计不需要） |
| **Identity / Environment Lock** | ❌ | ✅ **独有**（跨镜视觉锁定） |
| **站位与人物调度** | ❌ | ✅ **独有**（双人镜左右关系锁定 + 站位参考图复用） |
| 景别 / 角度 / 构图档位 | 7 景别 / 5 角度 / 6 构图法 | **7 景别**（含美式中景）/ **8 角度**（含低机位贴地）/ **9 构图** |
| Negative Prompt | ❌ | ✅ |
| Midjourney 参数 / 画幅档位 | 部分（画幅专项） | ✅ `--ar` `--stylize` + 5 档画幅 |
| 已接入图像生成 | ❌ | ✅（直接出图 / 九宫格 / 改图） |

### ⭐ 镜头技法词库（`引擎/镜头技法扩充库.md`）

`视觉分镜引擎.md §四` 是技法**骨架**（7 景别 + 8 角度 + 9 构图 + 13 运动 + 8 光影）；
本库是**肌肉**——从用户素材 `运镜50/`（47 张教学卡）提炼，按 6 类归位：

| 类 | 内容 | 性质 |
|---|---|---|
| A 运镜 | 17 条（含 **Dolly Zoom / 侧移曝光 / 穿越推进** 等 10 条新增） | 🟡 部分新增 |
| B 机位视角 | 15 条（含 **空镜头 / 客观镜头 / 主体锁定** 等 6 条新增） | 🟡 部分新增 |
| **C 焦点与光学** | 4 条（切换焦点 / 景深 / 变焦 / 脱焦） | ⭐ **全新类别** |
| **D 时间与节奏** | 4 条（慢动作 / 快动作 / 延时 / 运动模糊） | ⭐ **全新类别** |
| E 剪辑与结构 | 3 条（幻觉镜 / 空镜转主体；转场以 `04-视频生成` 为准） | 部分新增 |
| F 特殊机位 | 2 条（水下 / VR） | 新增 |

> ⚠️ **`运镜50` 的分类是混的**——里面混了景别、机位、焦点、时间、剪辑。本库已按项目体系**重新归位**，
> 不照抄源文件的"运镜"名称。
> ⚠️ **本库是词典不是检查表**——`§五·5.11` 已写明「不要滥用电影术语」，一条短剧用不到 64 种技法。
| 导演定调 / 节奏规划 | ✅ 六维定调 + 双轨节奏 | ❌（不做叙事调度） |

> ⚠️ **两者的 `Shot 01-09` / 分镜镜号不要混用**：视觉分镜的 Shot 编号属**视觉设计编号**；投产用的 `SHT_` 段由叙事分镜引擎登记进 `ID-REGISTRY.md`。
>
> ⚠️ **Identity Lock 必须与 `02-服化道` 的 Character DNA 一致**——以该角色 `ASSET_CARD.fixed_features` 为准，不得各写一套。

## 四、核心能力

### 五步主线

1. **剧本分析 + 导演定调** — 六维判断 + 七项视听决策 + 导演风格匹配库
2. **节奏规划** — 双轨节奏 + 五种镜头组 + 时长估算公式
3. **剧本微调** — 视听化修正 + 四焦点微调
4. **分镜拆解** — 叙事目的四类 + 镜头设计三武器 + 构图精修 + 光影设计
5. **AI 提示词转译** — 生图/生视频双模式 + 时间轴 + 转场衔接 + 尾帧连贯

### 第六步（可选扩展）

- **模式三**：网格宫格分镜图 / 25 宫格动态漫
- **模式四**：即梦 Z/Y/X 四维镜头模型
- **画幅专项**：**默认横版 16:9**，竖屏 9:16 仅小屏分发备用

### 平台速查

| 平台 | 模式 | 关键适配 |
|---|---|---|
| Midjourney / SD | 生图 | 英文 tag |
| Seedance 2.0 | 生视频 | 中文自然语言 + 禁 tag |
| 可灵 / Vidu / Sora | 生视频 | 中文自然语言 + 时间轴 |
| 即梦(视频) | 即梦四维 | Z/Y/X 参数 + ≥50 字/镜 |
| **短剧（默认横版）** | 视频模式 + 横版专项 | 16:9 + 三层纵深 + 前 3 秒钩子 |
| 提案沟通 | 宫格图 | 一图多镜 |
| 抖音动态漫 | 25 宫格 | Q 版 + 速度线 |

## 六、与其他模块的衔接

```
【01 剧本文本】剧本
        ↓
【02 服化道】角色/场景资产 + 风格锁定
        ↓
【03 分镜导演】← 本模块
        ↓
【04 视频生成】分镜转视频
```

本模块产出的分镜表可直接对接 `04-视频生成/` 的提示词体系；角色与场景引用 `02-服化道/` 的资产编号。

### ⚠️ ID 使用规则（不得自造）

| 规则 | 说明 |
|---|---|
| **ID 一律从 `01-剧本文本/模板/ID-REGISTRY.md` 读取** | `CHR_` / `CST_` / `PRP_` / `ENV_` / `POS_` 由 05 与 02 分配 |
| **本模块只负责登记 `SHT_` 段** | 格式 `SHT_S<场>_<3位>`（如 `SHT_S01_006`），出分镜表时一次性登记全场次 |
| **不得自造未登记 ID** | 分镜时发现需要新道具/新场景 → **回报 05 补登记**，不自行编号 |
| 前缀速查 | 角色 `CHR_` ｜ 服装 `CST_` ｜ 道具 `PRP_` ｜ **场景 `ENV_`** ｜ 动作 `POS_` ｜ 分镜 `SHT_` ｜ 音频 `AUD_` |

> 命名规范权威来源：`00-总控路由.md` §四。
