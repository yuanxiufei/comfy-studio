## Skill Goal

通过分析用户提供的剧本内容，智能识别场景边界和情绪转折点，为每个段落提供专业的分镜建议，包括景别选择、摄影机运动、构图参考，并匹配适合的导演风格参考，最终输出结构化的分镜表。

## Execution Steps

### Step One: 剧本接收与分析

接收用户提供的剧本内容，进行以下分析：
1. **场景识别**：识别场景切换点（INT./EXT. 场景标题、时间变化等）
2. **情绪分析**：识别情绪基调（紧张、温馨、悬疑、热血等）
3. **角色互动**：识别角色出场和互动模式
4. **动作描述**：提取关键动作和视觉元素

### Step Two: 智能分段

将剧本划分为适合拍摄的分镜单元：
- 每个分镜单元包含：场景信息、角色、动作、对话、情绪
- 标注建议的景别（大远景/远景/全景/中景/近景/特写/大特写）
- 标注镜头时长建议

### Step Three: 分镜建议生成

为每个分镜单元提供：

**1. 景别建议**
- 根据情绪强度和叙事需要推荐景别
- 考虑角色关系和空间关系

**2. 运镜建议**
- 摄影机运动方式（固定/推/拉/摇/移/跟/升降）
- 运动速度和节奏
- 镜头切换方式

**3. 构图建议**
- 画面构图法则（三分法、对称、引导线、框架等）
- 主体位置安排
- 景深建议

**4. 光影氛围**
- 光线方向（顺光/侧光/逆光/顶光）
- 色调倾向
- 明暗对比

### Step Four: 导演风格匹配

根据剧本类型和情绪，推荐参考导演：

**动作/热血类**
- 参考：扎克·施奈德、吴宇森、乔治·米勒
- 特点：快速剪辑、强烈视觉冲击、慢动作高潮

**悬疑/惊悚类**
- 参考：大卫·芬奇、克里斯托弗·诺兰、朴赞郁
- 特点：冷色调、不对称构图、心理压迫感

**文艺/情感类**
- 参考：王家卫、是枝裕和、理查德·林克莱特
- 特点：长镜头、自然光、细腻情感捕捉

**史诗/奇幻类**
- 参考：彼得·杰克逊、丹尼斯·维伦纽瓦、吉尔莫·德尔·托罗
- 特点：宏大场面、层次丰富、视觉奇观

**科幻类**
- 参考：雷德利·斯科特、丹尼斯·维伦纽瓦、斯派克·琼斯
- 特点：极简构图、冷峻色调、未来感美学

### Step Five: 输出分镜表

以结构化格式输出完整分镜建议：

```

分镜表 ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

【场景 X】场景名称 情绪基调：xxx 参考导演：xxx 风格

分镜 X.1 ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━ 内容：[剧本段落] 景别：xxx 运镜：xxx 构图：xxx 光影：xxx 时长：x秒 导演参考：xxx作品中的xxx手法 备注：xxx

[重复每个分镜...]

```

## Output Rules

1. **结构化输出**：使用清晰的标题和分隔线
2. **专业术语**：使用标准影视术语（景别、运镜等）
3. **具体可执行**：建议要具体，可直接指导拍摄
4. **导演参考**：每个分镜给出具体的导演/作品参考
5. **优先级标注**：标注哪些分镜是视觉重点
