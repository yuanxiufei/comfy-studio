# 宫格分镜生成器

## 执行步骤

### Step 1: 收集输入信息

向用户收集以下必要信息：

1. **参考图片**（可选）：核心场景图、人设图、风格参考图等
2. **剧情内容**：需要分镜化的剧情描述、剧本片段或故事大纲
3. **网格规格偏好**（可选）：2×2、2×2、3×3、3×4等，如用户未指定则智能推荐
4. **风格要求**（可选）：画风、色调、情绪基调等

### Step 2: 剧情分析与分镜规划

分析剧情内容，确定：

- **分镜数量**：根据剧情复杂度和节奏规划总镜头数
- **网格布局**：选择最适合的网格规格（如4个镜头→2×2，6个镜头→2×3，9个镜头→3×3）
- **镜头类型分配**：
  - 主镜头（Master Shot）：交代场景、建立空间关系
  - 特写镜头（Close-up）：刻画情绪、强调细节
  - 过肩镜头（OTS）：对话场景、人物关系
  - 动作镜头（Action）：动态瞬间、冲突高潮
  - 氛围镜头（Atmosphere）：环境渲染、情绪铺垫

**导演思维扩展原则：**
- 不局限于剧情文字描述的表面镜头
- 增加辅助镜头：反应镜头、过渡镜头、环境镜头
- 通过镜头语言强化戏剧张力
- 考虑镜头之间的节奏和呼吸感

### Step 3: 生成分镜提示词

为每个镜头生成详细的英文生图提示词，包含：镜头编号和类型、画面主体描述、构图和视角、光影氛围、情绪基调、风格关键词

### Step 4: 调用生图工具

使用生图工具批量生成宫格分镜图：
- 仅生成一张图，使用所有参考图和分析的结构，生成一张宫格分镜图
- 保持统一的风格和色调

### Step 5: 网格合成与输出

将生成的分镜图按规划的网格布局进行展示：

```
📋 分镜规划
- 网格规格: X×Y
- 总镜头数: N
- 剧情节奏: 起承转合分布

🎬 分镜详情
1. [镜头类型] 镜头描述...
2. [镜头类型] 镜头描述...
...

🖼️ 宫格分镜图
[生成的分镜图片网格展示]

💡 导演备注
- 镜头衔接说明
- 情绪曲线分析
- 建议的运镜/转场方式
```

## 注意事项

1. 网格布局需严格对齐，保持视觉整洁
2. 相邻镜头之间要有叙事逻辑和视觉连贯性
3. 重要情节可适当增加特写或强调镜头
4. 保持整体风格统一，避免突兀的视觉跳跃
5. 如用户提供了参考图，需在提示词中融入参考风格
