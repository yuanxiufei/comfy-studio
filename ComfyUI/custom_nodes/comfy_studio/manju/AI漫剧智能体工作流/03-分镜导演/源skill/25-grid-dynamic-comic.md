# 25宫格动态漫分镜

## Skill Goal

帮助用户将小说或剧本片段转化为专业的25宫格动态漫画分镜剧本。该技能专为抖音短视频风格的动态漫制作设计，支持悬疑惊悚与轻松搞笑风格的混合，包含丰富的特殊视角、速度线和画风突变标注。

## 触发条件

当用户需要生成25宫格动态漫画分镜时触发，关键词包括：25宫格分镜、动态漫分镜、分镜剧本、25格分镜、用户提供小说/剧本片段并要求转化为分镜格式。

## 工作流

### 步骤1: 接收输入
接收用户提供的小说/剧本片段，以及可选的风格设定参数。

### 步骤2: 分析文本结构
识别：场景切换点、情绪转折点（悬疑→搞笑→紧张）、角色动作和表情变化、关键剧情节点。

### 步骤3: 分配25格分镜
均匀分配到25个分镜中，确保：每格对应一个连续的画面、剧情连贯节奏流畅、悬疑和搞笑段落合理分布。

### 步骤4: 生成标准分镜格式
每个分镜包含：镜头编号(01-25)、景别(特写/近景/中景/远景/全景)、画面内容、特殊视角(可选)、速度线(方向+运动方式)、画风突变(Q版切换及夸张程度，可选)。

### 步骤5: 特殊视角分配策略

**悬疑紧张段落（至少3格）：**【急推】【鱼眼】【荷兰角】【透过门缝窥视】【POV主观】
**角色震惊段落（至少2格）：**【抽帧放大】【急甩】【大特写】【波浪变形】
**Q版搞笑段落（至少4格）：**【鱼眼】【广角畸变】【分屏同框】【俯拍Q版瘫倒】
**吐槽段落（至少2格）：**【越肩镜头】【视线匹配】【画中画】
**发现真相/高潮（至少1格）：**【上帝视角】【多重曝光】【镜像扭曲】【慢动作】

### 步骤6: 输出格式

```markdown
## 25宫格动态漫分镜剧本

【风格设定】
- 小说类型：悬疑惊悚
- 整体风格：轻松搞笑，Q版频繁
- 角色设定：主角是傲娇少女，Q版时常出现在吐槽时
- 节奏基调：悬疑时紧张压迫，搞笑时夸张轻快，形成强烈反差

### 镜头01
**景别：** [景别]
**画面内容：** [场景、人物动作、动态描述]
**特殊视角：** [视角名称]
**速度线：** [方向] + [运动方式]
**画风突变：** [如有，描述变形程度]

### 镜头02
...

【分镜统计】
- 悬疑紧张镜头：X格
- 搞笑Q版镜头：X格
- 特殊视角使用：X种
- 画风突变次数：X次
```

## 特殊视角库

### 基础运动
推、拉、摇、移、跟、甩、升降

### 速度型
【急推】【急拉】【急甩】【抽帧放大】【慢动作】

### 透视型
【长焦压缩】【俯拍】【仰拍】【上帝视角】【蚂蚁视角】

### 主观型
【POV主观视角】【越肩镜头】【视线匹配】【过肩镜头】

### 变形型
【荷兰角/斜角镜头】【波浪变形】【镜像扭曲】【多重曝光】

### 细节型
【微距特写】【大特写】【浅景深/焦外成像】【透过XX窥视】（如透过门缝/手指缝/玻璃水滴）

### 跟随型
【跟拍脚步】【跟拍视线】【跟拍动作轨迹】

### 拆分型
【分屏同框】【画中画】【碎片化构图】

## 速度线规范

### 方向
- 放射：从中心向外扩散，用于冲击、爆炸、震惊
- 平行：水平或垂直线条，用于快速移动、追逐
- 螺旋：旋转线条，用于眩晕、混乱、超自然现象

### 运动方式
- 流动：线条平滑流动，用于正常动作
- 脉冲：线条有节奏地跳动，用于紧张、心跳
- 震颤：线条剧烈抖动，用于恐惧、震惊

## 画风突变规范

### Q版变形程度
- 三头身：可爱Q版，用于轻松吐槽
- 豆豆眼：极度简化表情，用于无语、尴尬
- 下巴掉落：夸张震惊表情
- 泪腺喷发：夸张哭泣/感动
- Q版弹跳：弹性变形，用于活泼动作

### 标注格式
```markdown
【画风突变】三头身Q版，豆豆眼，表情夸张
```

## 注意事项

- **严格遵循原文**：分镜内容必须基于提供的文本，不添加原文没有的情节
- **节奏把控**：悬疑段落和搞笑段落要有明显区分
- **视角多样性**：25格中至少包含8种不同的特殊视角
- **Q版合理分布**：傲娇少女吐槽时优先使用Q版画风
- **速度线配合**：根据情绪选择合适的速度线类型
