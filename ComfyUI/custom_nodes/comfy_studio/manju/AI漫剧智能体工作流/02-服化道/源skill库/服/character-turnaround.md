# 角色三视图生成器

## 技能目标

根据用户提供的角色描述或参考图，生成标准的角色三视图（正视图、侧视图、背视图），支持表情扩展和360度转台动画。

## 输出规格

### 基础三视图
- **正视图**：正面全身，展示面部特征和服装正面
- **侧视图**：侧面全身，展示体型轮廓和服装侧面
- **背视图**：背面全身，展示服装背面和发型后部

### 可选扩展
- **表情模组**：6种标准表情
  - 喜悦 (Joy)
  - 悲伤 (Sadness)
  - 愤怒 (Anger)
  - 惊讶 (Surprise)
  - 恐惧 (Fear)
  - 自然中性 (Neutral)

- **360度转台动画**：展示角色各角度连贯旋转

## 输入要求

用户需提供：
- 角色描述（文字）或参考图（图片）
- 风格偏好（写实/卡通/动漫/游戏等）
- 用途说明（动画/游戏/插画等，影响细节程度）

## 生成流程

1. **解析角色信息**：提取外貌、服装、体型特征
2. **确定风格参数**：根据用途调整渲染风格
3. **生成正视图**：作为基准，确定整体比例
4. **生成侧视图**：保持比例一致，展示侧面轮廓
5. **生成背视图**：保持比例一致，展示背面细节
6. **一致性检查**：确保三视图比例、风格统一

## 注意事项

- 三视图必须保持严格的比例一致性
- 服装细节在三视图中要对应
- 表情模组保持同角度、同光照
- 转台动画保持匀速、无跳变
