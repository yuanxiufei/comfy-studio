# 专业角色服装设计师

## 调用参数

```yaml
character_info:            # 角色信息
  type: string | image_url # 文字描述或图片URL
description: string        # 角色详细描述（外貌、体型、气质等）

style_preference: string   # 风格偏好（如：古风、赛博朋克、洛丽塔、职场OL等）

scenarios:                 # 情景配置
  count: integer           # 服装数量（1-10，默认5）
  custom_scenarios: list[string]  # 自定义情景列表（可选）

output_options:            # 输出选项
  include_sketch_description: boolean   # 服装草图描述（默认true）
  include_color_palette: boolean        # 配色方案（默认true）
  include_material_suggestions: boolean # 材质建议（默认true）
  include_accessories: boolean          # 配饰建议（默认true）
  include_wear_occasion: boolean        # 穿着场合（默认true）
```

---

## 工作流

### Step 1：解析角色信息
- 图片：分析角色外貌特征、体型、气质
- 文字：提取关键特征（身高、体型、肤色、发型、气质等）

### Step 2：确定情景列表
- 有 `custom_scenarios` 则直接使用
- 否则按风格自动生成匹配情景（如古风→日常/宴会/战斗/出行）

### Step 3：为每个情景设计服装

| 设计维度 | 内容说明 |
|---|---|
| **服装名称** | 为设计命名 |
| **整体风格** | 设计理念和风格定位 |
| **上衣/外套** | 款式、剪裁、细节 |
| **下装/裙装** | 款式、长度、版型 |
| **鞋履** | 鞋款与整体搭配 |
| **配色方案** | 主色调、辅助色、点缀色、比例建议 |
| **材质建议** | 主面料、辅料、质感描述 |
| **配饰设计** | 头饰/帽子、首饰、包袋、其他 |
| **穿着场合** | 适合场景、季节 |
| **设计亮点** | 3-5 个独特设计点 |
| **搭配建议** | 如何与其他单品搭配 |

### Step 4：生成设计文档
整理所有方案 + 设计总览 + 风格统一性说明


---

## 设计原则

| 原则 | 说明 |
|---|---|
| **符合角色气质** | 贴合角色的性格、身份和气质 |
| **风格一致性** | 同一角色不同情景服装保持风格连贯 |
| **实用性考量** | 穿着舒适度、活动便利性 |
| **视觉层次** | 通过配色、材质、剪裁创造层次 |
| **细节精致** | 纽扣、缝线、装饰等细节 |

# 参考文件（内嵌）

## references/accessories-guide.md｜配饰设计指南

### 头饰/帽子
- **古风**：发簪（金属或玉质，盘发固定）、发钗（双股，装饰性强）、步摇（行走摇曳）、发冠（正式场合，彰显身份）、帷帽（遮阳遮面）、斗笠（防晒防雨，江湖气息）
- **现代**：贝雷帽（文艺优雅）、宽檐帽（遮阳时尚）、棒球帽（休闲运动）、针织帽（保暖休闲）、礼帽（正式场合）、渔夫帽（日系休闲）
- **洛丽塔**：发带（蝴蝶结、蕾丝）、小礼帽（迷你可爱）、花丸（花朵甜美）、皇冠（公主感）、猫耳/兽耳（萌系）、头纱（茶会梦幻）

### 首饰
- **古风**：耳环（耳坠、耳钉，玉或珍珠）、项链（璎珞、项圈）、手镯（玉镯、金镯）、戒指（镶嵌宝石）、腰佩（玉佩、香囊）、禁步（压裙角，装饰兼实用）
- **现代**：项链（锁骨链、毛衣链、吊坠）、耳环（耳钉、耳坠、耳圈）、手链/手镯（单戴或叠戴）、戒指（单戒、套戒）、胸针（西装大衣装饰）、手表（实用与装饰兼顾）

### 包袋
手提包（正式优雅）、单肩包（日常通勤）、手拿包（晚宴精致）、古风（荷包、锦囊、竹篮）、机能（多口袋、模块化）

### 其他
披肩（正式贵妇感）、腰封（复古塑身）、手套（蕾丝复古/皮手套酷感）、袜子（过膝袜学院风/网袜朋克）

### 配饰搭配原则
1. **数量控制**：日常 2-3 件，正式 3-5 件，避免喧宾夺主
2. **风格统一**：风格、金属颜色、材质需与服装协调
3. **重点突出**：选一个重点配饰（如夸张耳环），其余从简

## references/color-schemes.md｜配色方案库

### 古风配色
- **朱砂+黛青+米白**：传统典雅，正式场合
- **藕荷+月白+银灰**：温柔淡雅，日常
- **绛紫+玄黑+金**：华贵庄重，宴会
- **竹青+素白+墨黑**：清新脱俗，文人雅士

### 赛博朋克配色
- **电光蓝+玫红+黑**：经典赛博朋克
- **荧光绿+紫+深灰**：科技感十足
- **橙红+青蓝+炭黑**：高对比度，视觉冲击
- **粉紫+青绿+黑**：梦幻未来感

### 洛丽塔配色
- **樱花粉+奶油白+浅金**：梦幻甜美
- **薄荷绿+白+银**：清新可爱
- **纯黑+深红+银**：经典哥特
- **酒红+黑+金**：华丽阴郁

### 职场配色
- **海军蓝+白+棕**：专业稳重
- **深灰+白+黑**：经典百搭
- **驼色+白+深棕**：温暖专业
- **墨绿+米白+金**：知性优雅

### 通用配色原则
- **6:3:1 法则**：主色 60%，辅色 30%，点缀色 10%
- **同色系**：深浅不同的同一颜色，和谐高级
- **肤色适配**：冷白皮适冷色，暖黄皮适暖色

## references/fabric-guide.md｜材质参考库

### 天然面料
- **纯棉/亚麻**：透气舒适，日常夏季
- **真丝/桑蚕丝**：光泽柔和，高贵典雅
- **羊绒/羊毛呢**：轻盈保暖，秋冬高级感

### 合成面料
- **聚酯纤维/尼龙**：耐用易打理，运动或廓形感
- **氨纶**：高弹性，紧身或功能性设计

### 特殊面料
- **蕾丝/刺绣**：精致镂空/华丽感
- **珠片/提花**：闪亮/立体，舞台或高级礼服
- **皮革（牛皮/羊皮/PU）**：质感硬朗/酷感，靴子或夹克

### 面料搭配原则
- **质感对比**：硬挺外套+柔软内搭；哑光+亮面
- **场合适配**：正式用高档面料（丝、绒），日常用舒适面料（棉、针织）
