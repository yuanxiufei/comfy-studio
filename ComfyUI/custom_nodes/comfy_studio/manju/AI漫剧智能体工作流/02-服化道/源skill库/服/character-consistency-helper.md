# 角色一致性助手

## 技能目标

通过智能管理角色参考图，确保AI生成内容中角色外观的高度一致性，解决多镜头、多场景下角色"变脸"问题。

## 核心能力

### 1. 自动参考图注入
- 从长期记忆中读取已保存的角色参考图
- 自动将参考图附加到 image_generate 和 video_generate 调用
- 支持单角色和多角色场景

### 2. 智能角色匹配
- 根据分镜脚本中的角色列表自动匹配对应参考图
- 多角色场景下正确分配每个角色的参考图
- 支持角色别名和昵称识别

### 3. 提示词一致性优化
- 自动在提示词中注入角色外观特征描述
- 保持画风、色调与项目风格指南一致
- 优化负面提示词以避免角色特征漂移

### 4. 版本管理
- 支持角色多版本管理（正式版/候选版）
- 记录角色演变历史
- 快速切换不同版本的角色形象

## 执行流程

### 场景一：生成新分镜图时保持角色一致

1. **读取分镜信息** — 获取当前分镜脚本，提取当前镜头的角色列表和场景信息
2. **获取角色参考图** — 获取每个角色的参考图 URL 列表与场景参考图
3. **生成图像/视频** — 将参考图传入 `reference_images` 参数；在 prompt 中强化角色特征描述
4. **保存结果** — 记录使用的角色参考图版本

### 场景二：为已有角色生成新姿态/表情

1. **读取角色信息** — 获取角色列表并选择目标角色
2. **获取最新参考图** — 查看历史版本，获取当前正式版本的参考图
3. **生成新图像** — 使用参考图作为 `reference_images`；在 prompt 中指定新姿态/表情/动作；保持角色外观特征不变
4. **保存新版本（可选）** — 标记为 candidate 或 current

### 场景三：批量处理多镜头角色一致性

1. **获取完整分镜列表** — 获取所有镜头与已生成分镜
2. **识别缺失镜头** — 对比脚本和已生成帧，按场景分组优化批量顺序
3. **逐镜头生成** — 保持同一角色在所有镜头中参考图一致
4. **质量检查** — 对比生成结果中的角色特征，标记需重生成的镜头

## 使用示例

### 示例 1：生成包含主角的分镜图

```
用户：生成分镜 5，主角在雨中奔跑

系统：
1. get_shot_references(shot_characters=["主角"], shot_scene_name="雨夜街头")
2. image_generate(
     prompt="主角在雨中奔跑，雨水打湿头发，表情坚定...",
     reference_images=["主角参考图URL"],
   )
3. save_storyboard_frame(
     name="镜头05", shot_number=5,
     character_ref_urls={"主角": "主角参考图URL"}
   )
```

### 示例 2：为角色生成多角度视图

```
用户：为角色生成侧面视角

系统：
1. get_characters → 找到目标角色
2. get_character_versions → 获取当前参考图
3. image_generate(
     prompt="角色侧面视角，保持相同服装发型...",
     reference_images=["角色参考图URL"]
   )
4. save_character(version_status="candidate", change_note="添加侧面视角参考")
```

## 依赖工具

- `user_memory`：读取和保存角色/场景/分镜信息
- `image_generate`：生成保持角色一致的图像
- `video_generate`：生成保持角色一致的视频
- `report_progress`：向用户汇报处理进度

## 最佳实践

1. **首次使用前先保存角色** — 确保角色已有参考图存入记忆；建议保存正面清晰照作为基准
2. **多角色场景明确指定** — 在分镜脚本中清晰标注每个镜头的角色；使用统一的角色名称避免别名混淆
3. **定期更新角色版本** — 角色造型变化时保存新版本；用 version_status 区分正式版和候选版
4. **结合风格指南使用** — 先确认项目整体风格，角色生成时保持与项目风格一致

## 注意事项

- 角色参考图质量直接影响一致性效果
- 极端角度或大动作可能导致特征漂移
- 多角色同框时注意参考图数量和顺序
- 如生成结果不一致，可尝试调整参考图权重或增加特征描述
