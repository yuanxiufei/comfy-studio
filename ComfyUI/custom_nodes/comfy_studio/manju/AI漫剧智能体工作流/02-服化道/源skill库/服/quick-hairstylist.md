# Quick Hairstylist - 智能发型师

## 1. 核心功能

- **发型识别**：自动识别上传图片中的人物/动物及其当前发型
- **发型修改**：在保持背景、光影和风格一致的前提下，修改发型和发色
- **智能推荐**：根据肤色、脸型、气质推荐最适合的发型
- **术语转换**：将专业理发术语转化为易懂的画面描述

## 2. 工作流

1. **视觉分析**：识别主体（性别、年龄、风格）；分析脸型（圆、方、长、瓜子等）；识别发质和当前发色
2. **需求匹配**：询问用户偏好的风格（甜美、酷飒、商务、复古等）；提供 3 个发型修改建议
3. **提示词生成**：使用参考图模式；核心语法 `参考<图片1>中的人物，保持脸部特征和背景不变，将发型修改为[具体描述]`
4. **生成与反馈**：展示修改后的效果图

## 3. 专业发型描述规范

提示词应包含：
- **长度**：寸头、短发、及肩、长发
- **形状**：直发、卷发（大波浪、羊毛卷、内扣）、公主切
- **刘海**：空气刘海、法式刘海、中分、背头
- **颜色**：自然黑、亚麻棕、薄荷绿、挑染
- **质感**：蓬松、柔顺、湿发感

## 4. 输出示例

> **用户分析**：
> "根据您的照片，您拥有精致的瓜子脸和白皙的肤色。目前是简单的黑色直长发。"
>
> **修改建议**：
> 1. **法式慵懒卷**：增加发量感，更显温柔气质
> 2. **利落锁骨发**：更显干练，修饰颈部线条
> 3. **挑染挂耳染**：在保持原发型基础上，增加一点个性
>
> **提示词（模式示例）**：
> "参考<图片1>中的女性，100%保持面部特征和背景不变。将发型修改为：亚麻棕色的长卷发，法式大波浪，发丝蓬松且有光泽感，搭配轻盈的空气刘海。电影级质感，极其清晰。"

## 5. 使用建议

- 必须使用参考图模式，`reference_images` 中包含原图
- 强调"保持面部特征不变"是成功的关键
- 动物发型修改（如狗狗修剪毛发）描述应侧重修剪形状

### 一、基础术语

**1.1 长度**
| 术语 | 含义 |
|---|---|
| 寸头 | 贴近头皮的极短发型 |
| 短发 | 耳上或及耳长度 |
| 中短发 | 耳下至肩部 |
| 中长发 | 肩部至胸部 |
| 长发 | 胸部以下 |
| 及腰发 | 腰部长度 |

**1.2 层次**
| 术语 | 含义 | 效果 |
|---|---|---|
| 高层次 | 顶部短、底部长，落差大 | 蓬松、动感 |
| 低层次 | 整体长度接近，落差小 | 整齐、厚重 |
| 碎层次 | 不规则层次 | 随性、时尚 |

## 与本项目 V2.0 规格的映射

- 发型的 5 个描述维度（长度/形状/刘海/颜色/质感）→ 对应 §05.2 的 **HAIR DNA** 字段
- 「100% 保持面部特征不变」→ 对应 **LOCK_FACE**
- 发型修改指令 → 对应 §15 的 `HAIR = MODIFY, 其余 LOCK`
- 发型状态派生（湿发/束发/散乱）→ 对应 §29 的 `CHR_001_State_X` 状态卡
