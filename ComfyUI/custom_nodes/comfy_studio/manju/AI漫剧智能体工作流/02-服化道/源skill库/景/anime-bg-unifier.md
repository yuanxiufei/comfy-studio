# 动漫统一背景工具

## 功能概述

将多张动漫图片中的角色保留（动作、姿态、表情、形象不变），只替换背景，使所有角色处于同一新场景中。智能分析角色站位、方位、镜头角度，推算角色在新场景中的合理位置。

---

## 输入参数

| 参数名 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `images` | array | 是 | 需要统一背景的动漫图片URL列表（2-6张） |
| `new_scene` | string | 是 | 新场景描述（文字描述）或背景图URL |
| `scene_type` | string | 是 | `description`（文字描述）/ `image`（上传背景图） |
| `lighting` | string | 否 | 光照方向：`morning`/`noon`/`evening`/`night`，默认自动匹配 |
| `perspective` | string | 否 | 透视角度：`auto`/`low`/`eye`/`high`，默认 auto |
| `character_scale` | string | 否 | 角色大小一致性：`uniform`（统一大小）/ `preserve`（保留原比例），默认 preserve |

## 工作流程

### 第一步：分析输入图片

1. **角色识别**：提取角色形象、服装、姿态、表情
2. **原背景分析**：识别原场景类型、光照、透视
3. **角色位置**：确定角色在原图中的位置、朝向、大小
4. **镜头信息**：分析摄像机角度（平视/俯视/仰视）

### 第二步：新场景构建

**`scene_type = "description"`**：根据文字描述生成/搜索合适的背景图；分析描述中的空间信息（室内/室外、开阔/狭窄）

**`scene_type = "image"`**：分析上传的背景图；提取透视、光照、景深信息；确定可用空间区域

### 第三步：角色位置推算

**位置推算逻辑：**

1. **原图相对位置映射**
   - 左 → 新场景左侧区域 ｜ 中 → 中央区域 ｜ 右 → 右侧区域
   - 前 → 前景层 ｜ 后 → 背景层

2. **镜头角度适配**
   - 原图低角度 → 新场景保持低角度感
   - 原图平视 → 保持平视
   - 原图俯视 → 保持俯视感

3. **景深层级分配**
   - 根据原图角色大小推算远近
   - 大角色 → 前景/中景 ｜ 小角色 → 中景/远景

4. **互动关系保持**
   - 原图角色有对视/互动 → 新场景保持相对位置关系
   - 单人图 → 根据姿态推算最佳站位

### 第四步：背景替换处理

1. **角色抠图**：精确提取角色（保留头发丝、透明物体细节）
2. **边缘融合**：处理角色与新背景的边缘过渡
3. **光影匹配**：根据新场景光照调整角色光影；添加环境光、反射、投影
4. **透视校正**：根据推算位置调整角色透视
5. **色彩统一**：统一色调，确保角色与新场景协调

### 第五步：一致性检查

- ✅ 所有角色处于同一背景
- ✅ 光照方向一致
- ✅ 透视角度协调
- ✅ 角色之间比例合理
- ✅ 整体画面风格统一

## 位置推算算法

### 基础映射

```
水平位置：
- 原图偏左 → 新场景左侧 1/3 区域
- 原图居中 → 新场景中央区域
- 原图偏右 → 新场景右侧 1/3 区域

垂直位置：
- 原图偏上 → 新场景中后景
- 原图居中 → 新场景中景
- 原图偏下 → 新场景前景

深度位置：
- 原图角色大 → 新场景前景/中景
- 原图角色小 → 新场景中景/远景
```

### 高级推算

```
互动关系保持：
- 对视角色 → 保持面对面角度
- 并肩角色 → 保持并排站位
- 追逐角色 → 保持前后距离

镜头适配：
- 低角度原图 → 角色仰视感保留
- 平视原图 → 角色正常透视
- 俯视原图 → 角色俯视感保留
```

## 与本项目 V2.0 规格的映射

| 本文机制 | V2.0 规格对应 |
|---|---|
| 保留角色只换背景 | §32「允许变化：天气/时间/灯光状态」+ 锁定「建筑/空间关系」 |
| 光影匹配（按新场景光照调整角色光影） | §46「换场景时 LIGHTING = MODIFY IF NEEDED」的落地方法 |
| 位置推算（水平/垂直/深度） | §32「主空间关系」+ §27「多角色尺度关系稳定」 |
| `character_scale: uniform` | §27「身高差/体型差必须稳定」 |
| 一致性检查 5 项 | §18 CONSISTENCY ENGINE 的多角色专项 |
| `depth_layer` / `layer_order` | §12 SHOT ENGINE 的「Foreground / Midground / Background」 |

### 实用价值

本 skill 解决的是**「已有角色图，要统一到同一场景」**的场景，适用于：
- 多角色已在不同背景出图，需要合成同框
- 场景更换（§46「换场景」）时保留角色不变
- 快速做多角色同框预览，验证 §27 的尺度关系是否成立
