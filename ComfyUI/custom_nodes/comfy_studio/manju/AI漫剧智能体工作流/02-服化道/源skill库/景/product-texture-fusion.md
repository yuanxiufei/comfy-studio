# 产品纹理融合 (Product Texture Fusion)

## 概述

用于将图案 B 精准贴合到产品 A 的表面，实现专业级的产品贴图效果。通过高精度的曲面映射与光影统一算法，确保图案随产品结构自然变形，达到"真实存在"的视觉效果。

---

## 支持场景（三类）

| 类型 | 说明 | 适用 |
|---|---|---|
| **服饰/布料类** | 贴合布料的细微纹理、褶皱与垂坠感 | 衣服、包包、家纺 |
| **硬面产品** | 精准匹配圆柱、圆球或不规则曲面的透视，并融合环境反光 | 杯子、礼盒、五金、亚克力 |
| **简约扁平文创** | 将图案作为装饰元素融入画面版式 | 海报、包装、贴纸、卡片 |

---

## 质量指标（四项）

| 指标 | 要求 |
|---|---|
| **自然变形** | 图案必须遵循产品表面的几何起伏 |
| **光影统一** | 图案的色温、明暗分布必须与原图 A 保持一致 |
| **边缘无缝** | 彻底消除硬边、白边、悬浮感或毛刺 |
| **真实感** | 最终画面必须达到"一体化"的写实水平，无明显拼凑痕迹 |

---

## 工作流（六步）

1. **分析图 A**：识别产品结构、曲面曲率、光源方向及环境色
2. **预处理图 B**：根据产品属性调整图案的比例与色域
3. **几何映射**：执行高精度曲面贴合计算
4. **材质融合**：叠加图 A 的表面质感（如纤维、光面感）到图 B 上
5. **光影修正**：根据环境光源调整图案的阴影与高光
6. **生成结果**：输出最终融合图及三格对比图

## 与本项目 V2.0 规格的映射

| 本文机制 | V2.0 规格对应 |
|---|---|
| **四项质量指标** | **可扩展 §23 QUALITY CONTROL 的 Postflight 检查项**（规格检查"材质"但未给标准） |
| 分析「光源方向及环境色」 | §04.5 Lighting Bible（贴合必须匹配项目光影） |
| 预处理比例与色域 | §04.4 Color Bible 的约束 |
| **光影修正（按环境光源调整阴影与高光）** | **对应 §46「换场景时 LIGHTING = MODIFY」的细节层** |
| 材质融合（叠加表面质感） | §04.3 Material Bible |
| 三格对比图输出 | 可补入 §23 的**质检留痕**做法 |

### 应用场景（本项目）

| 场景 | 用法 |
|---|---|
| 服装纹样贴合 | 设计好纹样 → 贴合到 `CST_00X` 服装资产上 |
| 道具材质替换 | 同一道具换材质（青铜 → 玉）时保持结构不变 |
| 场景装饰图案 | 壁纸、旗帜、招牌等（**注意：不含可读文字**） |

### 建议的落地动作

把四项质量指标写入 `引擎/CONSISTENCY-CHECKLIST.md` 的 Postflight，作为**材质维度的量化验收标准**：
- 图案是否遵循表面几何起伏
- 色温明暗是否与底板一致
- 边缘是否有硬边/白边/悬浮感
- 是否达到"一体化"（无拼凑痕迹）
