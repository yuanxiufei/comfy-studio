# 画风守护者

## 核心功能

1. **参考图分析** — 提取色彩、光影、绘画风格、维度等特征
2. **风格提示词生成** — 输出标准化、可直接复制到视频生成工具的提示词
3. **风格一致性检查** — 对比新素材与参考风格的匹配度

---

## 风格维度（五个）

- **绘画风格**：油画、水彩、素描、赛博朋克、像素风、动漫、写实、概念艺术等
- **色彩调性**：暖色调、冷色调、高饱和、低饱和、单色、互补色、复古色调等
- **光影效果**：柔和光、硬光、逆光、体积光、霓虹光、自然光、电影光等
- **维度风格**：2D 平面、2.5D、3D 渲染、等距视角、手绘感等
- **质感特征**：颗粒感、平滑、手绘笔触、数字渲染、胶片感等

---

## 工作流程

### 功能一：分析参考图并生成风格提示词

用户上传参考图并要求分析画风时：

1. **分析图片，提取五维特征**：绘画风格 / 色彩调性 / 光影效果 / 维度质感 / 整体氛围
2. **生成结构化输出**：

```
【画风特征提取结果】

🎨 绘画风格：[具体风格]
🌈 色彩调性：[色彩特征]
💡 光影效果：[光影特征]
📐 维度风格：[2D/3D等]
✨ 质感特征：[质感描述]
🎭 整体氛围：[氛围描述]

━━━━━━━━━━━━━━━━━━━━━━
【可直接使用的风格提示词】

[风格], [色彩], [光影], [维度], [质感], [氛围], highly detailed, consistent style

━━━━━━━━━━━━━━━━━━━━━━
【负面提示词参考】

inconsistent style, different art style, varying colors, mismatched lighting
```

3. 向用户展示提取结果和生成的提示词

---

### 功能二：风格一致性检查（⭐ 核心价值）

用户上传参考图和新素材时：

1. **分别分析两张图的五维风格特征**
2. **逐维度对比匹配度**
3. **输出检查报告**：

```
【风格一致性检查报告】

参考图：[文件名/描述]
检查图：[文件名/描述]

━━━━━━━━━━━━━━━━━━━━━━
📊 整体匹配度：[X]%

━━━━━━━━━━━━━━━━━━━━━━
📋 各维度匹配度：

🎨 绘画风格：[匹配度]% - [差异说明]
🌈 色彩调性：[匹配度]% - [差异说明]
💡 光影效果：[匹配度]% - [差异说明]
📐 维度风格：[匹配度]% - [差异说明]
✨ 质感特征：[匹配度]% - [差异说明]

━━━━━━━━━━━━━━━━━━━━━━
💡 调整建议：

[根据差异最大的维度给出具体调整建议]
```

---

### 功能三：系列视频风格指南

用户需要为系列视频创建风格指南时：

1. 分析参考图并提取完整风格特征
2. 生成「风格指南文档」，包含：
   - 核心风格关键词
   - 推荐使用的正面提示词
   - 需要避免的负面提示词
   - 各维度的具体参数建议

---

## 匹配度评估标准

| 匹配度 | 等级 | 说明 |
|---|---|---|
| 90-100% | 优秀 | 风格高度一致，可直接使用 |
| 70-89% | 良好 | 风格基本一致，轻微调整即可 |
| 50-69% | 一般 | 有明显差异，需要针对性调整 |
| <50% | 较差 | 风格不匹配，建议重新生成 |

---

## 提示词生成原则

1. **准确性** — 基于图片实际特征，不臆测
2. **通用性** — 提示词适用于同风格的不同内容
3. **简洁性** — 避免冗余词汇，保留核心风格词
4. **结构化** — 按风格/色彩/光影/维度/质感组织

---

## 使用示例

**示例1｜分析参考图**：用户「帮我分析这张动漫图的画风，生成提示词」→ 分析图片 → 提取风格特征 → 输出结构化提示词

**示例2｜风格检查**：用户「这是我参考的赛博朋克风格，检查这张新图是否匹配」→ 分别分析两图 → 对比各维度 → 输出匹配度报告

**示例3｜系列风格指南**：用户「我要做 10 集动画，基于这个风格，给我风格指南」→ 深度分析参考图 → 生成完整风格指南文档

## 与本项目 V2.0 规格的映射

| 本文机制 | V2.0 规格对应 |
|---|---|
| 五维风格特征 | §04 WORLD BUILDER 的 Color/Lighting/Material/Camera Bible + `visual_style` |
| **匹配度百分比评分** | **§18 CONSISTENCY ENGINE 的量化补充**（规格只要求输出"冲突项/风险等级"，未给评分方法） |
| 匹配度四档标准 | 对应 §18 的 P0-P3 风险分级 |
| 系列视频风格指南 | §28 多集漫剧规则（跨集 `LOCK_COLOR` / `LOCK_LIGHTING`） |
| 负面提示词 | §22 NEGATIVE PROMPT ENGINE 的风格专项 |
| 调整建议基于最大差异维度 | §42 冲突处理优先级的执行方法 |

### 与同批次 skill 的分工

| skill | 角色 |
|---|---|
| `style-extractor` | **提取**风格 DNA（从参考图到风格字符串） |
| `style-guardian` | **校验**风格一致性（量化评分 + 差异定位） |
| `storyboard-lighting-master` | **统一**光影（批量重绘到同一预设） |

三者构成「风格锁定 Gate」的完整闭环：**提取 → 统一 → 校验**。

### 建议的落地动作

1. **把匹配度评分纳入 `CONSISTENCY-CHECKLIST.md`**：在 18 项检查外，新增「风格匹配度」一项，<70% 判 P1、<50% 判 P0
2. **每批资产出图后跑一次风格检查**：作为 `10_CONSISTENCY/` 的常规动作
3. **跨集开工前校验第一镜**：提前发现漂移
