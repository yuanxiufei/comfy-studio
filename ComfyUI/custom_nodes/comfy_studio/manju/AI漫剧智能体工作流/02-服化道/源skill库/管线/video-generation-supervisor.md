> **本文解决的问题**：AI 视频生成失败率高，但 V2.0 规格只给了"失败修复"（§24）的**内容层面**方案，缺少**工程层面**的重试与保障机制。本 skill 补上了这一层。

# 视频生成监督器

## 核心特性

- **失败自动重试**：生成失败时**保留原参数**，自动重新开始
- **循环保障**：持续重试直到成功或达到最大次数
- **进度实时汇报**：向用户报告当前执行状态
- **自动素材管理**：成功后自动上传到项目素材库

## 使用场景

1. 单视频生成
2. 批量生成多个视频任务
3. 高可靠性需求的生产任务

---

## 参数说明

### 必需参数

| 参数 | 类型 | 说明 |
|---|---|---|
| `prompt` | string | 视频生成提示词 |

### 可选参数

| 参数 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `image` | string | None | 参考图片 URL（图生视频时使用） |
| `model_name` | string | - | 视频生成模型 |
| `generate_type` | string | `t2v` | `t2v` 文生视频 / `i2v` 图生视频 |
| `aspect_ratio` | string | `16:9` | `16:9` / `9:16` / `1:1` |
| `duration` | number | 5 | 视频时长（秒）：5 或 10 |
| `sound` | boolean | true | 是否生成音效 |
| `max_retries` | number | 3 | 最大重试次数 |
| `upload_to_project` | boolean | true | 是否自动上传到项目素材库 |
| `project_id` | string | None | 项目 ID |
| `name` | string | None | 视频名称 |

---

## 工作流程

### 1. 初始化任务
验证必需参数 / 设置重试计数器 / **记录原始参数配置**

### 2. 执行生成
调用 `video_generate`，传递所有参数，等待返回

### 3. 结果处理

**成功：** 解析视频数据 → 提取视频 URL 和缩略图 → 如开启上传则上传到项目库 → 返回成功结果

**失败：** 检查重试次数 → 未达上限则**保留原参数重新生成** → 达上限则返回失败结果

### 4. 进度汇报

实时汇报四个节点：开始生成时 / 每次重试时 / 成功时 / 最终失败时

---

## 返回值说明

**成功：**
```json
{
  "success": true,
  "video_url": "https://...",
  "thumb_url": "https://...",
  "material_id": "mat_...",
  "retries": 0,
  "message": "视频生成成功"
}
```

**失败：**
```json
{
  "success": false,
  "error": "达到最大重试次数，生成失败",
  "retries": 3,
  "message": "视频生成失败"
}
```

---

## 注意事项

1. **重试策略**：失败时**完全保留原参数重试，不做任何修改**
2. **最大重试**：建议 3-5 次，避免无限循环
3. **上传依赖**：上传素材需要有效的 `project_id`
4. **时长限制**：支持 5 秒 或 10 秒
5. **模型选择**：确保使用平台支持的模型名称

## 与本项目 V2.0 规格的映射

| 本文机制 | V2.0 规格对应 |
|---|---|
| **失败保留原参数重试** | **§41 总循环的重试层**（规格只描述了行为顺序，未给失败重试机制） |
| 最大重试次数（3-5 次） | 防止无限循环的工程约束 |
| 进度实时汇报 | §41 各环节的状态反馈 |
| 成功后自动上传素材库 | §41 的 ASSET UPDATE 环节 |
| 与 §24 FAILURE 的关系 | **§24 是"改提示词再试"（内容层），本文件是"原参数重试"（工程层）——两者互补，顺序应为：先原参数重试 → 仍失败再改提示词** |

### 建议的落地动作

1. **把重试机制写进 `04-视频生成/00-主控智能体.md`**：明确"同一镜失败先原参数重试 2 次，仍失败才走失败修复表改提示词"
2. **失败登记表增加 retries 列**：记录每个镜头重试次数，用于排查共性失败
3. **批量生成时统一 max_retries**：避免个别镜头无限占用额度
