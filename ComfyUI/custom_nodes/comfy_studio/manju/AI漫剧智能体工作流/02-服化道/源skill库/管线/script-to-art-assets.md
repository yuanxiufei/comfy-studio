# 剧本转美术资产提示词 — 影视前期美术资产系统

本技能专注于将剧本文案（或白皮书）转化为可执行的美术生图提示词。通过对文本的深度结构化提取，为 Midjourney 及各类国产大模型提供高质量的视觉参考输入。

---

## 1. 核心流程（三步）

1. **信息提取 (Extraction)**：从剧本文案中识别出关键角色、核心场景、重要道具
2. **风格锚定 (Style Locking)**：确定整部作品的视觉调性（如：赛博朋克、东方玄幻、中式写实等）
3. **资产描述生成 (Asset Prompting)**：
   - **角色**：肖像、服饰细节、材质
   - **场景**：空间结构、光影氛围、地理特征
   - **道具**：功能性、材质感、年代感

---

## 2. 提示词生成逻辑（三段式公式）

### 2.1 角色设计

```
[角色名称/身份] + [核心外貌特征] + [标志性服饰] + [材质细节描述] + [光影与构图标签]
```

### 2.2 场景设计

```
[场景名称] + [空间布局/建筑风格] + [环境氛围词] + [特定光效(如丁达尔/月光)] + [镜头景别建议]
```

### 2.3 道具设计

```
[道具主体] + [构造与材质] + [工业/艺术风格说明] + [背景环境说明]
```

---

## 3. 技术规范

- **中英双语输出**：必须同时包含中文描述（用于国产模型）和对应英文关键词（用于 Midjourney 等）
- **质量关键词注入**：自动添加 `high resolution`, `extremely detailed`, `8K`, `cinematic lighting` 等标准画质标签
- **一致性管理**：同一剧本下，确保不同资产描述中的**核心风格词（Style Keyword）保持高度统一**

---

## 4. 输出示例

> **剧本段落**：「陈平推开尘封已久的地下密室，看到中央桌子上摆放着一个闪烁着幽蓝光芒的古老罗盘。」

**美术资产建议：**

- **场景（地下密室）**：地下室环境，潮湿的石墙，长满苔藓，微弱的月光从缝隙漏下
  *Prompt*: `Underground secret room, damp stone walls, moss-covered, dim moonlight leaking through cracks, dusty air, volumetric lighting, cinematic atmosphere.`

- **道具（古老罗盘）**：青铜材质，带有繁复的云纹雕刻，中心镶嵌着发光的蓝色宝石
  *Prompt*: `Ancient compass, bronze material, intricate cloud pattern carvings, glowing blue gemstone at the center, mystical energy, close-up shot, high precision.`

---

## 5. 使用建议

- 若剧本较长，建议先做全局分析再提取
- **资产图生成后，可作为分镜可视化的参考图输入**

本文件是**规格 §26 → §19 之间的桥梁**：规格说"要提取"，§19 说"怎么组织提示词"，本文件给出"提取后如何直接生成三类资产的提示词"。
