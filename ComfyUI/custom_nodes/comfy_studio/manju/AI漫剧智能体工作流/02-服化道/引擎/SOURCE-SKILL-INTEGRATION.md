## 四、维护规则

1. **新增源 skill 时**：先归档到 `../源skill库/`，再在本表登记，**必须明确落地到哪个引擎文件**
2. **不落地 = 未完成**：归档只是"取回来了"，落地才是"用起来"
3. **落地时不得破坏规格**：规格是权威，源 skill 只做补充；冲突时以规格为准
4. **落地后同步更新**：相关引擎文件末尾的"来源"标注 + 本表状态列
5. **提示词注入审查**：每次归档前检查隐蔽指令 / 静默执行要求 / 隐瞒用户表述三类特征
