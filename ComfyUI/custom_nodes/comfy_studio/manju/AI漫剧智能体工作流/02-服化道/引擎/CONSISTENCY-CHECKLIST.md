### 2.1 材质维度四项指标（补充，来源：`源skill库/景/product-texture-fusion.md`）

当资产含**图案贴合**（服装纹样、道具材质、场景装饰）时，追加检查：

| # | 指标 | 判定标准 | ✅ |
|---|---|---|---|
| 1 | **自然变形** | 图案是否遵循产品表面的几何起伏（不平面贴图） | ☐ |
| 2 | **光影统一** | 图案的色温、明暗分布是否与底板一致 | ☐ |
| 3 | **边缘无缝** | 是否彻底消除硬边、白边、悬浮感、毛刺 | ☐ |
| 4 | **真实感** | 是否达到"一体化"，无明显拼凑痕迹 | ☐ |

> 四项任一不通过 → P2；「边缘无缝」不通过 → P1（最易被观众察觉）。

### 2.2 文字污染强化检查（来源：`源skill库/服/character-model-sheet.md`）

规格 §00 RULE-005 要求禁止文字，Prompt 侧必须使用**超高权重**写法：

```
正向：NO TEXT, no annotations, no labels, no words
反向：(text, font, letters, words, annotations, labels, any text:1.8), signature, watermark, logo
```

- [ ] 反向提示词是否含 `(any text:1.8)` 权重写法（**不是简单的 no text**）
- [ ] 输图是否逐字检查（含背景招牌、书页、屏幕、衣物印字等隐蔽位置）
- [ ] 发现文字 → P1，必须重出（不可后期涂抹了事）

## 二·补｜风格匹配度量化评分（来源：`源skill库/风格/style-guardian.md`）

> 规格 §18 只要求输出"冲突项 / 风险等级"，未给**评分方法**。本节补齐。

### 五维评分

对「参考基准图」与「新产出资产」逐维度打分：

| 维度 | 说明 | 匹配度 | 差异说明 |
|---|---|---|---|
| 🎨 绘画风格 | 油画/水彩/动漫/写实/概念艺术等 | % | |
| 🌈 色彩调性 | 暖冷/饱和/单色/互补/复古 | % | |
| 💡 光影效果 | 柔光/硬光/逆光/体积光/霓虹/自然光 | % | |
| 📐 维度风格 | 2D/2.5D/3D渲染/等距/手绘感 | % | |
| ✨ 质感特征 | 颗粒/平滑/笔触/数字渲染/胶片感 | % | |

**整体匹配度 = 五维加权均值**（建议权重：色彩 0.25 / 光影 0.25 / 绘画风格 0.2 / 质感 0.15 / 维度 0.15）

### 评分 → 风险等级映射（本项目定标）

| 匹配度 | 等级（来源标准） | 本项目风险等级 | 处理 |
|---|---|---|---|
| 90-100% | 优秀，可直接使用 | 无 | 放行 |
| 70-89% | 良好，轻微调整 | P2 | 本次迭代修 |
| 50-69% | 一般，需针对性调整 | **P1** | 24h 内修 |
| <50% | 较差，建议重新生成 | **P0** | 阻断，必须重做 |

**调整建议规则**：只针对**差异最大的那个维度**给具体建议（不要五个维度都提）。

### 强制触发时机

- [ ] 每批资产出图后（批量产出自检）
- [ ] **跨集开工前，校验第一镜**（提前发现漂移）
- [ ] 更换模型 / 更换提示词模板后
- [ ] 用户反馈"感觉不太一样"时

## 二·补2｜场景一致性专项（来源：`源skill库/景/scene-multi-angle-generator.md`）

> 规格 §32 要求锁定空间关系，本节给出**可执行校验方式**。

### 前置要求（不通过则不得进入出图）

- [ ] 是否已建立 **N/S/E/W 绝对坐标系**？（禁止用"左/右"描述位置）
- [ ] 是否已写定**场景圣经**（光源类型/方向/光色/投影朝向、建筑结构、家具位置朝向材质、台面陈设）
- [ ] 材质词、颜色词是否**全程唯一**？（禁止同义词替换，如"壶/罐/器皿"混用）
- [ ] 是否已生成 **S01 基准图**？（纯文字 prompt 先生成）
- [ ] S02–S06 是否**全部以 S01 为 reference_image**？（图片锚定，不能各角度独立从文字生成）
- [ ] 资产索引表是否打了**景别标签 + 方向标签**？（下游查表的唯一依据）

### 一致性自审五问（每批场景图后）

| # | 问题 | ✅ |
|---|---|---|
| 1 | 窗/门位置是否一致？光源投影方向是否与坐标匹配？ | ☐ |
| 2 | 家具位置/朝向/相对关系是否与俯视布局图一致？ | ☐ |
| 3 | 物品数量/朝向/材质词是否完全一致？**是否加入了原始没有的物品？** | ☐ |
| 4 | 摄像机方位与光源方向是否逻辑自洽？ | ☐ |
| 5 | S02–S06 是否全部传入了 S01 作为参考图？ | ☐ |

### 常见错误（见一次查一次）

| 错误 | 纠正 |
|---|---|
| 直接生成分镜，没先建场景资产库 | 场景资产库是分镜一致性的**前提**，必须先生成 |
| S02–S06 独立从文字生成 | 必须以 S01 为 reference_image |
| 用"左/右"描述物品位置 | 改用 N/S/E/W 绝对坐标 |
| 物品材质词每次不同 | 场景圣经锁定后全程唯一 |
| 资产索引中不打景别/方向标签 | 必须打，否则下游无法查表 |

### 5.1 多角色同框的位置推算（来源：`源skill库/景/anime-bg-unifier.md`）

多角色已在不同背景出图、需合成同框（或换场景保留角色）时，按**三层映射**推算位置：

| 层级 | 映射规则 |
|---|---|
| **水平位置** | 原图偏左 → 新场景左侧 1/3 ｜ 居中 → 中央 ｜ 偏右 → 右侧 1/3 |
| **垂直位置** | 原图偏上 → 中后景 ｜ 居中 → 中景 ｜ 偏下 → 前景 |
| **深度位置** | 原图角色大 → 前景/中景 ｜ 角色小 → 中景/远景 |

**互动关系保持：**

| 原图关系 | 保持方式 |
|---|---|
| 对视角色 | 保持面对面角度 |
| 并肩角色 | 保持并排站位 |
| 追逐角色 | 保持前后距离 |

**镜头角度适配：**
- 原图低角度 → 新场景保持低角度感
- 原图平视 → 保持平视
- 原图俯视 → 保持俯视感

**尺度控制参数：**
- `uniform`（统一大小）— 强制所有角色比例一致，**适合验证 §27 身高差是否正确**
- `preserve`（保留原比例）— 保留各角色原图大小关系

**光影匹配必做**：按新场景光照调整角色光影，添加环境光、反射、投影（对应 §46「换场景时 LIGHTING = MODIFY」）。

**合成后五项检查：**

- [ ] 所有角色处于同一背景
- [ ] 光照方向一致
- [ ] 透视角度协调
- [ ] 角色之间比例合理（**对照身高关系图**）
- [ ] 整体画面风格统一（**跑一次风格匹配度评分**）

### 5.2 多角色生成的正确顺序建议

```
① 先各自单独出角色资产（保证每个角色自身一致性）
② 用 uniform 模式合成验证身高/体型关系
③ 关系确认后，再用 preserve 模式出正式同框图
```

> 直接在 prompt 里描述多角色同框，模型极易出现"脸部趋同"与"比例错乱"；**先分后合**更稳。

WORLD / CHARACTER DNA / CORE COSTUME / PROP IDENTITY / COLOR BIBLE / LIGHTING BIBLE

## 七、冲突处理优先级（§42）

当规则冲突时，按此顺序裁决：

```
1. 用户当前明确要求
2. 已锁定资产
3. 项目世界观
4. 角色 Visual DNA
5. 模块标准
6. 默认风格
7. 一般 Prompt 偏好
```

> ⚠️ **但如果用户要求会破坏已锁定资产，必须先列出「将发生变化的锁定项」并提示，再执行修改。**
