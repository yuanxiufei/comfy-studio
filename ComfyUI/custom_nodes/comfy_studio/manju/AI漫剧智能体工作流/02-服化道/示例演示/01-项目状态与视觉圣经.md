## 二、VISUAL_BIBLE（§04 填充示例）

### 4.1 基础世界观

| 项 | 内容 |
|---|---|
| 时代 | 当代 |
| 地域 | 临江市（虚构南方都市，多雨） |
| 文明 | 现代都市文明 |
| 社会结构 | 旧城平民区 / 新兴资本阶层双轨 |

| 生活方式 | 都市通勤、夜班工作、雨季潮湿生活 |

### 4.2 建筑

| 项 | 内容 |
|---|---|
| 建筑类型 | 90 年代旧公寓楼 / 现代玻璃幕墙写字楼 / 法医实验室 |
| 结构 | 砖混老楼（低矮、楼道逼仄）；钢构玻璃塔（高耸、过度整洁） |
| 比例 | 老楼层高 2.8m 压迫；写字楼通高开阔 |

| 墙体 | 老楼道斑驳涂料+小广告痕迹（**注意：不含可读文字**） |
| 家具 | 老楼旧木柜铁床；写字楼极简金属 |
