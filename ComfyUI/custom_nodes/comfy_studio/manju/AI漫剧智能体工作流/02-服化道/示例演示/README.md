## 使用方法

1. **照抄结构**：新项目直接复制本目录，替换内容
2. **对照填写**：每个字段都给了填充范例，填空即用
3. **验证规格**：把 `03-资产卡与提示词.md` 的 Prompt 拿去实跑，看产出是否符合预期

## 两类示例的区别

| 类型 | 文件 | 用途 |
|---|---|---|
| **规格流程演示** | `03`–`05` | 走 V2.0 规格的六步工作流 + 三闸门，展示**决策层**产物形态 |
| **引擎实跑验证** | `01` | 走 `01-资产库出图引擎.md`，展示**执行层**产物，并暴露集成缺口 |

> ⚠️ `01` 的价值不在"证明能跑通"，而在**用真跑暴露机制缺口**——它的 4 个发现（材质库覆盖不足 / 库外无规则 / 缺资产卡优先 / 补全结果无落点）已回补进引擎。
> **方法论**：新增引擎后必须实跑，且必须用**规格样例之外**的输入。
