# PROJECT VISUAL BIBLE · 流氓天尊

> 02 服化道产出（规格 §26 十四项）｜ 依据：`01_WORLD/世界观.md` + EP01–EP05 剧本
> ⚠️ **本文件是全项目视觉的唯一锚点**：任何资产的提示词都不得与它冲突

---

## 1. 世界观 / World
当代都市 + 隐藏的修真体系（**现代为壳、界外为里**）。
EP01–EP05 只需要表达"普通人生活里裂开一道缝"，**不许**把修真元素画进日常空间。

## 2. 时代 / Era
当代（现在线）；**六年前**为同一都市的上层圈层（无年代差异，只有阶层差异）。

## 3. 地域 / Geography
虚构 `S 市`。⚠️推断：视觉参考**沿海一线城市的旧城区**（旧砖、铁门、窄楼道）
＋ 郊外庄园。**不做**明显地域方言化（不挂地域标识物）。

## 4. 整体风格 / Style
**写实 / 拟真人 / 电影级**（规格 §22 默认）。
⚠️ **唯一例外**：EP02–EP05 的喜剧笑点允许**一次**漫画符号外挂
（头顶三条斜线 + 瀑布汗），**仅限该镜**，不得扩散到角色资产三视图。

## 5. 色彩语言 / Color（★ 本项目最重要的视觉设定）

本项目用**三条色线**区分三个时空 —— 这是 EP01 唯一的视觉叙事手段：

| 线 | 场景 | 主色 | 辅助 | 禁止 |
|---|---|---|---|---|
| **现在线** | 医院 / 萧家客厅 / 街道 | 冷白 `#E9EDF0` + 灰蓝 `#5A6B7A` | 铁灰 `#3A3F46` | ❌ 暖黄光、饱和色 |
| **六年前线** | 天龙庄园 | 暖金 `#C9A063` + 深棕 `#3A2E24` | 酒红 `#6E2B2B` | ❌ 冷白光、霓虹 |
| **界外线** | 深山水潭 / 悬浮小屋 | 冷雾青 `#8FA9A6` + 幽蓝 `#2E4756` | 灰白 `#B9BCB4` | ❌ 任何暖色、金色 |

**跨线规则**：同一人物跨线时，**脸不变、色温变**（例：`CST_001` 冷灰 → `CST_002` 深棕）。

## 6. 光影体系 / Lighting

| 线 | 主光 | 用途 |
|---|---|---|
| 现在线 | **单一顶光源**（日光灯管）+ 大面积暗部 | 普通人的处境；走廊用"门缝透光"做视觉钩 |
| 六年前线 | **暖侧光**，允许半脸阴影 | 萧林龙**始终不露全脸**（只有半脸在光里） |
| 界外线 | **无明确光源**：水面反光 + 雾中散射 | 超然、不可测 |

**通用**：柔和均匀、无明显硬阴影、真实光线衰减、物理合理反射（规格 §5.1 Light）。
**禁止**：赛博霓虹、影视剧式打光（本剧不是爽文爽拍）。

## 7. 材质体系 / Material
医院：水磨石 / 旧地砖 / 白漆铁门 / 日光灯管 / 棉布
萧家（普通市民）：贴皮木家具 / 沙发布罩 / 塑料收纳箱 / 玻璃茶几
庄园（顶级）：深色实木护墙板 / 黄铜灯具 / 皮革沙发 / 大理石
界外：苔石 / 木 / 雾中水面
⚠️ 道具的材质必须与**阶层**一致 —— 「萧家的东西不能看着贵」。

## 8. 建筑体系 / Architecture
老式住院楼（窄走廊、地砖、灯管）；普通三居室客厅（家具紧凑、有生活杂物）；
庄园（主楼 + 独立别墅两栋 + 开阔庭院）；深山（平地 + 水潭 + **离地一人高的悬空小屋**）。

## 9. 服装体系 / Costume
按**阶层 × 场合**分档（详见 `INDEX_COSTUME.md`）：
- 普通市民：干净合身、无品牌、基础色 → 李茜是**全剧唯一暖色块**（米白/浅蓝/淡粉）
- 顶级圈层（六年前）：深色定制、无 Logo、靠剪裁与袖扣说话
- 界外：素灰长袍，**无纹无饰**（不是华丽仙侠风）

## 10. 道具体系 / Props
只给**有叙事功能**的道具编号。
⭐ 三大母题道具：`PRP_001 香烟`（焦虑的可见化）· `PRP_009 九转珍珑戒`（全剧核心）
· `PRP_010/011 两串"地摊项链"`（**必须真的做得廉价** → 后续打脸的伏笔）

## 11. 镜头语言 / Camera
- 现在线：手持微晃、近景为主、景深浅
- 六年前线：稳定机位、对称构图、景深清楚
- 界外线：固定机位、**长时间静止**（"不动"比运动更神秘）
- ⚠️ **喜剧段落**（EP02/EP04/EP05）允许一次快剪，但**不许**做成综艺花字

## 12. 氛围 / Atmosphere
现在线：夜、消毒水味、疲惫（用烟头、灯管闪烁、地砖反光表达）
六年前线：暖、安静、压抑（用层高、剪影、雪茄烟表达）
界外线：雾、冷、无时间（用水面白气、无光源表达）

## 13. 人物一致性 / Consistency
- **脸部锚点优先级最高**（骨相 > 五官 > 发型 > 服装）
- 同一角色跨时空/跨年龄：**脸型与五官比例不变**，只变装扮与体型
- ⭐ 三人固定锚点：萧易「叼烟 / 先笑再说话」· 李茜「说狠话前歪一下头」· 萧林龙「不露全脸」
- ⭐ 师父「眼睛先入画」—— 他的登场方式就是他的锚点

## 14. 图像标准 / Image Standard（全项目默认）

```
Aspect Ratio : 16:9
Resolution   : 8K UHD / 工具最高可用
Style        : photorealistic / semi-realistic / cinematic
Detail       : extremely high
Character/Costume/Props : 纯白背景 + 左侧放大细节 + 右侧 正面/侧面/背面 三视图
Environment  : 真实场景背景 + 多角度（不用纯白背景）
Lighting     : 柔和均匀、电影级、无明显硬阴影
TEXT/LOGO/WATERMARK : ❌ 一律禁止（含 FRONT/SIDE/BACK 等标签）
```
