## CHR_001｜萧然

**基础信息**
- 别名：然然（李茜在后续集使用，⚠️推断）
- 年龄：EP01 = **出生当日**（0 岁）
- 性别呈现：男
- 身份／职业：天龙集团继承人（血统）· 现为普通家庭之子
- 社会地位：出身顶级家族，成长环境为普通市民阶层

**性格**（EP01 只呈现"天生不凡"的种子，性格靠后续集展开）
- 关键词：眼珠灵动、不哭、四处张望
- 矛盾点：⚠️待后续集建立

**外貌要点（供服化道直接用，≥5 处）**
1. 新生儿，皮肤泛红、微皱（原文：刚出生）
2. 眼睛**睁着**、眼珠转动灵活（原文：「一双小眼睛四处张望着」）
3. 哭几声即停（原文：「婴儿只哭了几声就停了下来」）
4. ⚠️推断：胎发较密、偏黑
5. ⚠️推断：眉眼间距略宽（为后续"成年萧然"留连续性锚点）
6. ⚠️推断：手指修长（冰灵果易筋洗髓的先天底子，EP03 起有戏）

**关键特征（可识别锚点，1-2 个）**
- ⭐ **睁眼不哭**（全集唯一的"异常感"来源 → 这是本剧的第一个视觉符号）
- ⚠️推断：眉心被拇指按过一下（EP01 S05，可作后续"被师父点过"的母题）

**服装逻辑**
- EP01 仅 1 套：`CST_005` 婴儿襁褓（白色棉布、医院制式 ⚠️推断）
- 色彩倾向：全白（与两条成人线的"冷白/暖金"都区分开）

**内在**
- 核心欲望：⚠️待后续集
- 致命弱点：⚠️待后续集
- 人物弧光：出生（EP01）→ 被收徒（EP02–03）→ 炼体/入世（EP04+）

**台词特征**
- EP01 无台词（婴儿）
- 后续：⚠️待补（原文 4 岁起有"心想"式吐槽 → 短剧须改为**可见反应 + 短台词**，不可用旁白）

## CHR_002｜萧易

**基础信息**
- 别名：萧老板（护士称呼）
- 年龄：⚠️推断 35 前后（六年前约 29）
- 性别呈现：男
- 身份／职业：天龙集团**继承人（已放弃）** · 现为 S 市小公司老板
- 社会地位：表面中层商人 · 真实出身顶级家族（**观众到 EP01 结尾才知道**）

**性格**
- 关键词：吊儿郎当、嘴硬、认死理
- 矛盾点：为爱情放弃一切，却始终没告诉妻子"放弃了什么"

**外貌要点（供服化道直接用，≥5 处）**
1. 原文：「长的说不上很帅」→ 五官普通、耐看型（**不要**做成偶像脸）
2. ⚠️推断：方脸偏短，下巴有青胡茬
3. ⚠️推断：眉较粗、眉尾稍下垂（显疲态）
4. ⚠️推断：单眼皮或内双，眼白有血丝（熬夜）
5. ⚠️推断：鼻梁直、鼻翼略宽
6. ⚠️推断：身高偏高、肩宽、体型偏瘦（旧西装穿着显松）

**关键特征（可识别锚点，1-2 个）**
- ⭐ **嘴上永远叼着烟**（焦虑的可见化 → `PRP_001`）
- ⭐ 逗人时先笑再说话（六年前后**同一个习惯**，跨时空识别的锚点）

**服装逻辑**
- 阶层：对外是"小公司老板" → 衣服不起眼；六年前是"庄园少爷" → 但李茜面前**不摆架子**
- 场合：EP01 现在 = 深夜陪产（`CST_001` 旧外套 + 衬衫）；六年前 = 庄园夜（`CST_002` 深色西装，松领口）
- 色彩倾向：现在线深灰/铁蓝；六年前深棕/酒红。**不用亮色**

**内在**
- 核心欲望：守住自己选的人
- 致命弱点：**从不肯解释**（对父亲不解释、对妻子不说实情）
- 人物弧光：从"放弃家族" → "被家族与外界重新找上来"（EP01 老人出场是这条线的起点）

**台词特征**
- 语速：偏快，逗人时故意拖长
- 用词：短句、口语、爱反问（「你就这么想嫁给我？」）
- 口头禅：⚠️推断「顺其自然」（EP01 起名时用了一次，可作母题反复）

## CHR_003｜李茜

**基础信息**
- 别名：茜
- 年龄：⚠️推断 33 前后（六年前约 27）
- 性别呈现：女
- 身份／职业：⚠️推断 婚后持家（原文：一个人在家没事干）
- 社会地位：普通市民家庭 · 婚前是"学校里追的人有一个排"的类型

**性格**
- 关键词：直率、护家、嘴上不饶人
- 矛盾点：**骂得最凶、疼得最深**（对丈夫、对儿子都是同一套）

**外貌要点（供服化道直接用，≥5 处）**
1. 原文：「不可多得的美女」→ 骨相好，素颜也立得住
2. 原文：产后「发白的脸上全是汗水，但是也当不住她的风情」
3. ⚠️推断：鹅蛋脸，眉形柔和，眼尾微微下垂
4. ⚠️推断：鼻小巧、唇形饱满
5. ⚠️推断：产后头发被汗浸湿，贴在额头与鬓角（EP01 必须保留这个细节）
6. ⚠️推断：体态纤细（产后虚弱期）

**关键特征（可识别锚点，1-2 个）**
- ⭐ 说狠话时**先歪一下头**（同一动作在两时空都出现）
- ⭐ 六年前与现在**同一款短发**（她不因嫁入/离开而改变 → 人物底色）

**服装逻辑**
- 阶层：不追品牌、干净合身为主
- 场合：EP01 产房 = `CST_003` 病号服；六年前居家 = `CST_004` 素色针织裙
- 色彩倾向：米白 / 浅蓝 / 淡粉（**全剧唯一的暖色块**，与两条男性线的冷/暗对冲）

**内在**
- 核心欲望：把日子过好（原文：夫妻俩生活得很甜蜜）
- 致命弱点：先入为主（EP01 六年前会错意；**第 3 节把师父当乞丐/骗子** → 同一弱点的连续后果）
- 人物弧光：从"被保护者" → "护住这个家的人"（EP01 已埋：她要"报警、打电话给你爸"）

**台词特征**
- 语速：快，句子短，一句一个信息
- 用词：口语、爱反问、爱重复对方的话
- 口头禅：⭐ **「你这个流氓」**（原文原话 → 剧名母题，跨集复用）

## CHR_004｜萧林龙

**基础信息**
- 别名：董事长（⚠️推断）
- 年龄：⚠️推断 60 上下（六年前）
- 性别呈现：男
- 身份／职业：天龙集团董事长
- 社会地位：顶层（原文：手握万亿美圆巨资）

**性格**
- 关键词：不容置疑、讲利益、冷
- 矛盾点：**说话用"为家族着想"包装强迫**（原文原话）

**外貌要点（供服化道直接用，≥5 处）**
1. 原文：「十分威武的中年人」
2. ⚠️推断：国字脸、发际线后移、白发打理整齐
3. ⚠️推断：眉浓且直、眼神平（不怒自威）
4. ⚠️推断：鼻翼宽、法令纹深
5. ⚠️推断：体型偏壮，正装撑得起
6. ⚠️推断：指间常年雪茄（**EP01 的"手部表演"道具**）

**关键特征（可识别锚点，1-2 个）**
- ⭐ **始终不露全脸**（EP01 只给背影 + 半脸阴影 → 关系断裂的视觉化，且留"以后露脸"的爆点）
- ⚠️推断：说狠话前先把雪茄灰弹一下（与萧易的"叼烟"形成父子对照）

**服装逻辑**
- 阶层：顶层 → 深色定制正装、无 Logo、袖扣细节
- 场合：EP01 = 夜间在书房见儿子（`CST_006`）
- 色彩倾向：黑 / 深棕 / 暗金

**内在**
- 核心欲望：家族利益最大化（原文：两家联合，无人是对手）
- 致命弱点：把家人当资产
- 人物弧光：⚠️待后续集（EP01 只建立"他掌握着儿子的出身秘密"）

**台词特征**
- 语速：慢，不换气，不解释
- 用词：陈述句，不带情绪词，**从不用问句**
- 口头禅：⚠️推断「你下去吧」（EP01 逐客 = 他结束话题的唯一方式）

## CHR_005｜老人（师父）

**基础信息**
- 别名：爷爷（他对萧然自称，见第 2–3 节）· 老头（萧然称呼）
- 年龄：⚠️推断 外貌 60+，实际极大（界外人物）
- 性别呈现：男
- 身份／职业：⚠️推断 山中人 / 修士（原文未在本集点明）
- 社会地位：无（EP01 只有背影）

**性格**
- 关键词：笃定、居高临下、有耐心
- 矛盾点：能看穿人心，却要"哄"一个孩子吃果子（第 2–3 节的喜剧来源）

**外貌要点（供服化道直接用，≥5 处）**
1. 原文：「灰扑扑的头发随意散在肩」
2. 原文：皮肤「象年轻人一样的光洁有弹性」（**关键：老年身形 + 青年皮肤**）
3. 原文：「一双眼睛尤如黑夜中的星辰，那么的耀眼，仿佛能看穿你的内心」
4. ⚠️推断：身形清瘦、背挺直
5. ⚠️推断：衣袍无纹无饰、灰白（**不是**华丽仙侠风）
6. ⚠️推断：手部皮肤年轻但指节粗大（练家子的手）

**关键特征（可识别锚点，1-2 个）**
- ⭐ **眼睛**（唯一被原文详细描写的部位 → 全剧最重要的表情资产）
- ⭐ EP01 只给背影（信息差：观众先知道"有人要收徒"，萧然自己还不知道）

**服装逻辑**
- 阶层：不属世俗阶层
- 场合：山居中，`CST_007` 素灰长袍（离地、无尘 ⚠️推断）
- 色彩倾向：灰白 / 冷青（与"深山线"主色一致）

**内在**
- 核心欲望：收徒（原文：「这个徒弟我收定了」）
- 致命弱点：⚠️待后续集
- 人物弧光：⚠️待后续集

**台词特征**
- 语速：极慢
- 用词：短、笃定，不用商量语气
- 口头禅：⚠️推断「终于入世了」（EP01 起，可作他每次"出手"前的信号句）

## CHR_006｜护士（⚠️ 简版小传，仅 1 句台词）

**基础信息**
- 年龄：⚠️推断 25 前后 · 女性
- 身份／职业：市医院产房护士
- 定位：功能性配角（**只出场一次**）

**外貌要点**（⚠️全部为推断）
1. 圆脸、短发、束在护士帽下
2. 护士服 + 口罩（EP01 建议**戴口罩** → 降低资产成本与漂移风险）

**关键特征**
- ⚠️推断：把襁褓递出时双手先停一下（怕家属接不稳）

**台词特征**
- 一句话一个信息（原文：「恭喜萧老板，是个公子。」）
