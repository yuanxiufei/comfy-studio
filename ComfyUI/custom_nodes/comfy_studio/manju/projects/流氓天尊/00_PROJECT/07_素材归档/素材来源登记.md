## 二、参考素材来源（每一张图、每一条音都要能回答"哪来的"）

| 素材文件 | 用途 | 来源（作者 / 站点 / 链接） | 许可 | 可商用 | 已归档 |
|---|---|---|---|---|---|
| | 角色参考 | | CC0 / CC BY / 自有 / 授权 | ☐ | ☐ |
| | 场景参考 | | | ☐ | ☐ |
| | 音乐 / 音效 | | | ☐ | ☐ |

**许可一栏怎么填**（不要写"网上找的"）：

| 写法 | 含义 |
|---|---|
| `自有` | 我方原创或已买断 |
| `CC0` | 无需署名，可商用 |
| `CC BY` | **必须署名** —— 记下署名文字 |
| `CC BY-SA` | **署名 + 相同方式共享**（本项目内置词库用的就是它） |
| `授权` | 有凭证，凭证在 `归档清单.md` 对应行 |
| `未知` | ⛔ 视同**不可用**，不得进入产物 |

> ⚠️ **`未知` 一律不许用** —— 它会在 S7 合规审核时被拦下，
> 而那时画面已经出完了。
