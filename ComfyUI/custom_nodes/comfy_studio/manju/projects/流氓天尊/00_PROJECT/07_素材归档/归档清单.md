# 归档清单 · 流氓天尊

> **本文件管什么**：**入库了什么**（文件级事实）——
> 来源/许可的**判断**在 `素材来源登记.md`，本文件只记**文件本身**。
>
> 为什么要这份：半年后要回答"这张参考图哪来的、能不能商用、哪个版本的"，
> 靠回忆必然答错。**有校验值的清单**才能证明"入库后没被换过"。

## 二、归档去哪（与 `项目目录规范.md` 的分工）

| 素材性质 | 放哪 |
|---|---|
| 项目**自己的**过程资料与产物 | 本项目目录（`00_PROJECT/` … `11_AUDIO/`） |
| 工作区级的**原著文本** | 工作区 `novel/`（跨项目共享的原始输入） |
| 大体积二进制（视频/音频中间件） | 本项目目录对应阶段目录，**按集分目录** |
| 外部素材原件 | 本项目 `00_PROJECT/07_素材归档/` 下按类别分子目录，或按方决定的外部归档位 |

> ⚠️ **别把大体积中间件提交进版本库** —— 版本库只留**台账与文本**，
> 二进制产物按项目的备份策略处理。

## 三、生成校验值

```bash
# 单文件（Windows PowerShell）
Get-FileHash <文件> -Algorithm SHA256 | Select-Object -ExpandProperty Hash

# 整个归档目录（列出每个文件的摘要）
Get-ChildItem -Recurse -File <归档目录> | Get-FileHash -Algorithm SHA256
```
