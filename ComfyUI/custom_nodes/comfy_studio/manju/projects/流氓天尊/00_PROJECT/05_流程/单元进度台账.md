# 单元进度台账 · 流氓天尊

> ⚠️ **硬规则：本单元没回填，不开下一单元。**
>
> 为什么这么严：**进度脱节不报错**。剧本改了、加了角色，资产清单没跟着更新，
> 后果不是"报错"，而是**到分镜那天才发现这集画不出来** —— 那时返工成本最高。
> 出处：`生产流程规范（S0-S7）.md` §二·补（进度脱节 / 世界观脱节两个失效模式）。

## 二、回退规则（**改剧本要连累什么**）

| 情况 | 必须一起回退 |
|---|---|
| 剧本改了（加角色 / 改场景 / 改场次） | 本行的**资产 / 分镜 / 视频**三列全部回 ☐ |
| 资产升版（`_v2`） | 分镜 / 视频三列回 ☐（旧帧作废） |
| 换了视觉锚点 | **全表回 ☐** —— 这是全片级变更，不是单元级 |

> ⚠️ **只回退、不删除**：历史产物改名保留（`_v1` 不动），
> 因为已交付的下游可能还在引用它（出处：`生产流程规范（S0-S7）.md` §五 返工规范）。

## 三、单元收工的世界观抽查（每单元 3 问）

抽本单元新增资产 **2–3 条**，逐条问：

```
[ ] 色温属于本单元该有的那条线吗？
[ ] 材质符合该角色/场景的阶层吗？
[ ] 时代特征与世界观一致吗？
```

任一为 ❌ → **回到视觉圣经对一遍**，❌ **不要就地改图**
（就地改 = 漂移的开始，下次生成又会不一样）。
